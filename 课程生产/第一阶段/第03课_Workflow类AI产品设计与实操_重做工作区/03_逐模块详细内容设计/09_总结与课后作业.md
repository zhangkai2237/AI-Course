# 09 总结与课后作业（114—120分钟）

## 四句总结

1. Prompt控制一次模型处理，Workflow组织多步处理和分支；
2. 先画业务路径，再拖平台节点；
3. 需要理解语言时用模型，需要守住硬规则时用条件和固定输出；
4. 能跑只是起点，测试和边界决定它能不能成为产品。

## 课后作业

从自己的工作中选择一个同时满足“两步以上、存在分支、有明确兜底”中的至少两项的场景，完成《Workflow设计与测试单》V1.0。

必须提交：

- 一句话目标和明确不做什么；
- 输入、最终输出；
- 至少三条路径，其中一条是兜底或人工确认；
- 纸面流程图；
- 至少五条测试，含正常、模糊和高风险/异常输入；
- 一条失败记录与修正；
- 若使用平台，再附运行截图；没有账号可只交完整设计单。

## 验收标准

- 路径是按业务差异拆分，而不是为了多画节点；
- 每个节点有清楚的输入和输出；
- 高风险、实时数据或权限问题不由模型自由编造；
- 测试结果可以回到具体节点定位；
- 能用三分钟讲清“为什么这样分支”。
