# 模块六：风险、异常与人工接管

## 一、模块定位

- 建议时长：18 分钟
- 对应总课时：88—106 分钟
- 模块作用：建立 Agent 产品的最低安全意识
- 本课深度：会识别、会设计基本控制点，不展开完整治理体系

本模块不试图讲完安全、权限和评测。第 9 课再系统讲评测，第 10 课再系统讲安全与治理。本课只解决一个直接问题：

> 当 Agent 从“回答”走向“执行”后，产品经理必须在哪里设置控制点？

## 二、核心判断

### Agent 可以建议，不代表可以直接执行

同一句用户需求可能对应不同风险等级：

- “告诉我有哪些活动规则”：读取知识；
- “分析这家门店的数据”：读取业务数据；
- “给我一个活动建议”：生成内容；
- “创建一个活动草稿”：写入系统，但仍可修改；
- “直接发布活动”：影响真实用户和预算；
- “自动扣款或发放补贴”：涉及资金和不可逆后果。

产品经理不能只判断“模型能不能做”，还要判断：

- 做错后的影响有多大；
- 动作是否容易撤销；
- 是否涉及隐私、资金、真实用户或外部系统；
- 是否需要用户再次确认；
- 是否需要人工审批。

## 三、最低风险分级

| 动作类型 | 示例 | 默认控制方式 |
|---|---|---|
| 读取公开知识 | 查询活动规则 | 可直接执行，记录调用 |
| 读取业务数据 | 查询门店指标 | 校验身份与数据权限 |
| 生成建议 | 输出运营方案 | 标注依据，允许用户修正 |
| 创建草稿 | 创建活动草稿 | 执行前明确确认关键参数 |
| 对外发布 | 发布活动、发送消息 | 强确认或人工审批 |
| 资金与不可逆动作 | 扣款、发券、删除数据 | 默认禁止自动执行或采用严格审批 |

这张表是课堂中的最低判断框架，不是企业级权限规范。

## 四、两条判断轴

老师可以在白板上画一个二维坐标：

- 横轴：出错后的影响，从低到高；
- 纵轴：动作的可逆性，从容易撤销到难以撤销。

判断原则：

- 低影响、容易撤销：可以提高自动化程度；
- 高影响或难以撤销：增加确认、审批和人工接管；
- 同时高影响且难以撤销：默认不让 Agent 独立完成。

## 五、四类常见异常

### 1. 信息不足

例子：用户只说“看看最近数据”，没有门店和时间范围。

正确处理：

- 明确缺少什么；
- 只追问必要参数；
- 不自行猜测门店或日期；
- 信息补全后再调用工具。

### 2. 工具失败

例子：指标查询超时、门店不存在、规则服务无响应。

正确处理：

- 区分“无结果”和“调用失败”；
- 告知用户当前状态；
- 允许重试或更换处理方式；
- 不伪造一个看似合理的结果。

### 3. 权限或风险超界

例子：用户要求 Agent 直接发布活动，但当前只提供创建草稿工具。

正确处理：

- 说明当前可执行范围；
- 不用别的工具绕过限制；
- 可以创建草稿，但发布需人工完成。

### 4. 任务失控

例子：Agent 重复调用同一个工具，或者连续多次得到相同错误。

正确处理：

- 设置最大重试次数；
- 达到阈值后停止；
- 保留已经获得的有效结果；
- 清楚说明失败原因并建议人工接管。

## 六、确认卡设计

调用 `create_campaign_draft` 前，界面应显示一张结构化确认卡，而不是只问一句“是否确认”。

### 确认卡示例

> 即将创建活动草稿，请确认：
>
> - 门店：滨江路店
> - 活动目标：改善新客转化
> - 目标人群：近 30 天未下单的新注册用户
> - 优惠方案：满 50 减 8
> - 活动时间：8 月 1 日—8 月 7 日
> - 预算上限：5,000 元
> - 当前动作：仅创建草稿，不会直接发布

用户可以选择：

- 确认创建；
- 修改参数；
- 取消任务。

确认卡的价值不是“多一步操作”，而是让用户知道系统将要做什么，并有机会纠正关键参数。

## 七、停止条件与人工接管

### 建议停止条件

- 任务已完成；
- 用户主动取消；
- 必要参数长期无法补全；
- 同一工具连续失败；
- 返回结果互相冲突；
- 请求超出工具权限；
- 涉及未授权的高风险操作。

### 人工接管信息

转交人工时，不应只显示“处理失败”，而应保留：

- 用户原始目标；
- 已确认的参数；
- 已调用的工具；
- 工具返回结果；
- 当前失败位置；
- 推荐人工下一步。

这样人工不需要从头询问用户。

## 八、课堂快速判断

老师依次展示以下动作，请学员回答“可直接执行、需要确认、需要人工审批”：

1. 查询平台公开活动规则；
2. 查询已授权门店的经营数据；
3. 生成一段运营建议；
4. 创建活动草稿；
5. 向 10 万用户发送营销消息；
6. 自动发放高额补贴。

重点不在于得到唯一答案，而在于学员能否说出：

- 影响对象；
- 错误成本；
- 可逆性；
- 所需权限。

## 九、本课边界

本模块只建立最低可用的控制意识：

- 第 9 课再讲如何系统评测任务完成率、工具调用准确率和异常恢复；
- 第 10 课再讲权限、隐私、安全、审计和治理体系。
