# 模块04：个人语气RAG主实操

> 时间：90—123分钟  
> 产出：P2个人语气RAG图文Workflow  
> 核心边界：只学习表达方式，不学习历史文档事实

## 一、本轮解决的问题

P1能稳定生成图文，但表达仍然偏通用，难以保留讲师本人习惯：

- 如何从具体困惑开头；
- 如何解释复杂概念；
- 句子长短和语言节奏；
- 如何从现象转向误区和方法；
- 如何克制表达、避免焦虑营销；
- 如何用行动建议收口。

本轮使用RAG检索老师历史文字，但历史文字只用于抽象语气，不能作为新文章事实来源。

## 二、课堂核心公式

```text
事实来源＝本次source_material
表达语气＝历史文字抽象出的style_profile
输出体裁＝当前target_format和Prompt
```

历史文字可以是课程讲义、长文、产品分析、朋友圈、社群答疑或方法总结，不要求是小红书文案。

## 三、为什么不把历史原文直接交给写作节点

如果写作节点同时收到历史原文，模型可能：

- 把旧公司、旧项目和旧数据写进新文章；
- 继承历史文章的具体观点，而不是本次事实；
- 直接复制旧句；
- 把讲义结构照搬成小红书；
- 为了“像本人”而机械重复口头禅。

因此必须增加“语气提取节点”，并在变量层隔离原文。

## 四、语气样本准备

建议准备15—30篇老师本人真实写作。课堂最低可以先用8—10篇测试。

材料要求：

- 主要由本人写作；
- 是本人希望长期保留的表达；
- 每篇建议200—2000字；
- 可以跨体裁；
- 上传前删除当前公司、内部项目、客户和经营数据；
- 不使用他人代写、纯复制资料和无个人表达的会议记录。

## 五、目标流程

```text
Start
→ 输入检查
→ 生成语气检索问题
→ 检索历史表达样本
→ 判断是否命中
   ├─ 无命中 → 默认语气卡
   └─ 有命中 → 提取抽象语气卡
→ 内容角度与大纲
→ 按个人语气生成标题正文
→ 图片脚本/图片
→ 事实与语气审核
→ End
```

## 六、学员操作步骤

### 步骤1：导入并检查语气样本

学员完成：

- 上传脱敏历史文字；
- 检查文档是否解析；
- 抽查至少三个片段；
- 确认材料确实由本人撰写；
- 确认没有当前公司和敏感事实；
- 记录样本库名称和版本。

### 步骤2：生成语气检索问题

输入本次主题、受众、目标、体裁和语气要求，输出一条风格检索问题。

查询描述的是：需要什么表达视角、节奏和论述方式；不是查询历史文章中的事实答案。

### 步骤3：检索历史表达样本

建议检索3—5个最相关样本，并查看实际命中文档。

检索结果变量 `retrieved_style_samples` 只能进入语气提取和最终审核，不能直接进入标题正文节点。

### 步骤4：提取抽象语气卡

语气卡只保留：

- 表达视角；
- 开头习惯；
- 语言节奏；
- 论述结构；
- 概念解释方式；
- 转折与举例方式；
- 情绪强度；
- 专业与口语程度；
- 结尾习惯。

必须删除人物、公司、项目、案例、时间、数据和具体结论。

### 步骤5：写作节点只接两类输入

```text
source_material：本次唯一事实来源
style_profile：只控制怎样表达
```

历史原文不进入写作节点。输出仍由Prompt规定为小红书图文。

### 步骤6：事实与语气双审核

审核同时检查：

- 新内容事实是否来自source_material；
- 是否迁移历史文章事实；
- 是否疑似直接复制长句；
- 是否符合语气卡；
- 是否仍然符合小红书体裁；
- 图片是否新增无依据事实。

## 七、有无语气RAG对照

对同一个主题运行P1和P2，对比：

- 两版事实集合是否一致；
- P2是否更符合老师的开头、节奏和解释方式；
- P2是否为了模仿风格增加历史事实；
- P2是否仍然是小红书，而不是讲义或长文；
- 能否明确指出使用了哪些抽象语气特征。

## 八、边界测试

### 测试1：历史样本含无关事实

预期：风格卡和新文章都不出现旧公司、旧项目和旧数据。

### 测试2：非小红书样本

只使用讲义或产品分析样本。预期保留表达方式，但输出仍然符合小红书体裁。

### 测试3：无样本命中

预期使用默认克制语气，不声称已经学会老师风格。

### 测试4：疑似直接抄句

预期审核发现高度相似长句并要求重写。

### 测试5：本次素材为空

即使语气样本命中，也不得使用历史文章事实补足本次内容。

## 九、最低完成线

- 至少导入8篇脱敏历史文字，或使用老师已准备的课堂样本库；
- 查看至少三条真实检索片段；
- 生成一份不含具体历史事实的语气卡；
- 历史原文没有直接进入写作节点；
- 展示P1与P2的一处可解释语气差异；
- 通过“历史事实不迁移”和“非小红书样本迁移”测试。

## 十、本轮认知记录

> 个人语气RAG增加了________；历史文字只用于________；新文章事实仍然只能来自________。

参考答案：

> 个人语气RAG增加了可检索、可抽象的个人表达方式；历史文字只用于提取语气卡；新文章事实仍然只能来自本次输入。

## 十一、常见错误

- 把历史原文直接传给写作节点；
- 把“风格像”理解成历史事实也可以使用；
- 只上传两三篇短消息就判断个人语气；
- 样本由他人代写或风格差异过大；
- 只检查最终文案，不看语气卡；
- 输出像讲义而不是小红书；
- 机械重复口头禅；
- 原样复制历史长句；
- 样本中仍包含敏感信息。

## 十二、与P3的连接

P2作为 `run_xhs_rag_workflow` 工具提供给P3。Agent决定何时生成完整图文；P2内部负责：

```text
本次事实＋个人语气＋小红书体裁＋事实与语气审核
```
