## 一、本模块PPT设计原则

1. 第44—46页使用完全相同的诊断画布和计时流程；
2. 课前只填写学员明确授权公开的背景事实，不提前写方向结论；
3. 先确认事实，再提取资产，最后形成方向假设；
4. 学员说能力标签时，老师必须追问具体事件、责任和结果；
5. 每人只指出一个当前最大缺口，避免形成无法行动的长清单；
6. 每人必须得到“JD验证任务＋项目或学习验证任务”；
7. 信息不足时明确写“暂不确定”，不为了课堂效果强行判断；
8. 平台和解决方案建议必须使用条件表达并要求真实JD验证；
9. 不公开公司名、客户名、收入、业务数据或其他敏感信息；
10. 严格执行3人×8分钟＋3分钟总结，不让单人挤占全班时间。

### 单人8分钟固定流程

| 时间 | 课堂动作 | 页面填写位置 |
|---|---|---|
| 0:00—1:00 | 复述背景并确认目标 | A 背景事实 |
| 1:00—3:00 | 追问2—3个关键事实 | B 有效证据 |
| 3:00—4:00 | 提取六类资产 | C 主要资产 |
| 4:00—5:30 | 给优先与备选方向 | D 方向假设 |
| 5:30—6:30 | 指出一个最大缺口 | E 最大缺口 |
| 6:30—8:00 | 给JD＋项目任务并复述 | F 双验证任务 |

## 第44页｜现场诊断1

### 页面标题

> 现场诊断1｜从背景事实到下一步验证动作

### 页面上屏文字

#### A｜背景事实

```text
背景：行业／职能／年限
对象：长期服务谁
流程：最熟悉什么
```

#### B｜有效证据

```text
证据1：场景 → 责任 → 行动 → 结果
证据2：场景 → 责任 → 行动 → 结果
```

#### C｜六类资产中的主要证据

```text
主要资产：________／________／________
```

#### D｜方向假设

```text
优先：________  备选：________
或：当前暂不确定
```

#### E｜当前一个最大缺口

```text
______________________________________
```

#### F｜双验证任务

```text
JD：____份________方向岗位
项目／学习：________________
```

右上角固定计时器：

```text
08:00
```

### 版式结构

- 采用精简六区诊断画布，不做普通内容页；
- 左侧为A、B、C，右侧为D、E、F；
- 右上角固定8分钟倒计时；
- 方向区域使用四方向颜色，但未判断前全部保持灰色；
- 预留现场键入、手写批注或白板覆盖空间。

### 现场填写顺序

1. 先填A，复述并让学员确认；
2. 追问时只记录B中的事实，不立即解释；
3. 将事实归入C并标记证据等级；
4. 第4分钟后填写D；
5. 第5分30秒后只填一个E；
6. 最后填写F并完整复述V0.2。

### 老师关键追问

从下列问题中选择2—3个：

```text
你长期服务的用户或客户是谁？
你最熟悉的一条业务流程是什么？
在参与最深的项目里，你亲自做了什么决定？
这个决定产生了什么结果，怎样判断？
你是否用数据或指标做过判断？
你与哪些技术角色协作，推动到什么程度？
你是否承担过方案、试点、交付或验收？
```

### 时间控制提示

- 05:00：必须停止继续扩展背景；
- 06:00：必须进入最大缺口与行动建议；
- 07:30：开始完整复述结论；
- 信息不足时直接填写“暂不确定＋需要补充的证据”。

### 结果复述句式

```text
你的V0.2是：优先验证________，备选________；
依据是________和________；
当前最大缺口是________；
下一步完成________份JD分析，以及________项目任务。
这不是最终结论，完成任务后再调整。
```

### 老师备注来源（不投屏）

```text
课堂工具：T3—T5｜信息来自学员授权陈述｜方向结论需继续验证
```

### 对应讲义

- 第五部分“现场诊断的统一判断逻辑”；
- 第六部分“单人8分钟标准流程”；
- 第七部分“判断卡V0.2模板”。

## 第45页｜现场诊断2

### 页面标题

> 现场诊断2｜换一个背景，判断方法不变

### 页面上屏文字

本页完整复用第44页六区诊断画布：

```text
A 背景事实
B 有效证据
C 六类资产中的主要证据
D 优先与备选方向假设
E 一个最大缺口
F JD任务＋项目／学习任务
```

各填写字段、证据等级、计时器和结果复述句式均与第44页一致。

右上角计时器：

```text
08:00
```

### 版式结构

- 复制第44页母版，不改变位置、颜色和判断顺序；
- 清空第1名学员的所有现场批注；
- 只允许保留方法标签，不保留上一位的具体结论；
- 候选人课前授权的背景可预填，其余区域为空。

### 现场填写顺序

```text
确认事实 → 追问事件 → 提取资产 → 方向假设
→ 一个最大缺口 → JD与项目双验证
```

### 老师提醒

第二名学员通常与第一名背景不同，但老师不能为了制造差异而强行推荐另一方向。

若学员坚持想走一个证据较弱的方向，使用条件表达：

> 兴趣可以支持你投入验证，但当前证据不足以把它定为优先求职方向。我们先设计一个验证任务，看完成后是否出现新的证据。

### 时间控制提示

- 仍然严格8分钟；
- 不因为第1名已经讲过方法而省略事实确认；
- 不重复长篇讲解课程概念；
- 07:30必须开始复述V0.2。

### 老师备注来源（不投屏）

```text
课堂工具：T3—T5｜信息来自学员授权陈述｜不根据职业名称直接映射方向
```

## 第46页｜现场诊断3

### 页面标题

> 现场诊断3｜信息不足，也可以得到有效下一步

### 页面上屏文字

本页继续复用相同六区画布，并在D区额外保留一个选项：

```text

```

如果选择“暂不确定”，必须继续填写：

```text
当前可以确认的事实：____________________

先完成的验证动作：______________________

```

右上角计时器：

```text
08:00
```

### 版式结构

- 与第44、45页保持同一母版；
- “暂不确定”不是红色警告，使用中性蓝灰色；
- 如信息不足，D、E、F仍必须完成，不留空白；
- 页面不出现任何录用可能性或成功率判断。

### 现场填写顺序

仍然执行：

```text
事实 → 资产证据 → 方向假设／暂不确定
→ 最大缺口 → 双验证任务
```

### 老师提醒

如果学员缺乏工作和项目经历，不要为了让案例“有答案”而强行判断。可以这样说：

> 目前不足以可靠判断To B或To C。我们能确认的是，你需要先在一个可接触真实用户的场景中完成项目验证，再比较方向。

如果学员披露敏感信息，立即打断并抽象化：

> 具体公司、客户和数据不用讲。请只说明这是哪类流程、你承担什么责任，以及结果如何判断。

### 时间控制提示

- 信息越少，越不应无限追问；
- 第6分钟仍要进入行动建议；
- 输出“暂不确定”时，也必须给明确完成时间和验证材料；
- 07:30开始收口。

### 老师备注来源（不投屏）

```text
课堂工具：T3—T6｜允许“暂不确定”｜敏感信息不记录、不展示
```

## 第47页｜三个人答案不同，过程相同

### 页面标题

> 三个人的答案可能不同，但判断过程相同

### 页面上屏文字

#### 中央判断流程

```text
背景事实 → 资产证据 → 方向假设
→ 一个最大缺口 → JD＋项目验证
```

#### 页面右侧三个方法提醒

```text
不从职位名称直接下结论
不把兴趣或自评当成强证据
信息不足时不强行判断
```

#### 页面底部V0.2任务

```text
V0.2补充：
1条关键追问｜1条证据修正｜JD任务＋项目任务
```

### 版式结构

- 中央使用六步纵向流程；
- 左侧可放三位学员的匿名小卡，只显示“背景类型／主要资产／结论状态”；
- 右侧放三条方法提醒；
- 底部V0.2任务使用整行行动区。

### 动画顺序

1. 三位学员匿名小卡出现；
2. 六步流程从上到下展开；
3. 三条方法提醒出现；
4. 最后显示全员V0.2任务。

### 讲课动作

第1分钟比较不同：

> 三个人的经历、证据和下一步可能完全不同，所以方向答案不需要一致。

第2分钟强调相同：

> 我们每次都从事实出发，用六类资产和证据等级判断，再给一个可验证的方向假设。

第3分钟要求全员更新：

> 没有被分析不代表没有产出。请把刚才最有用的一次追问应用到自己身上，并补上JD和项目双验证任务。

### 老师备注来源（不投屏）

```text
课堂工具：T5｜V0.2仍为方向假设，不构成求职或录用结论
```

### 对应讲义

- 第十一部分“三名学员结束后的3分钟总结”。

## 二、现场操作与备选方案

### 1. 课前必须准备

- 课前问卷和公开授权；
- 三名背景差异较大的候选人；
- 每人一张预分析卡，但不预写确定结论；
- PPT现场批注、白板或叠加文本框；
- 桌面计时器或助教时间提示。

### 2. 时间不足时

| 剩余时间 | 调整方案 |
|---:|---|
| 27分钟 | 3人×8分钟＋3分钟总结 |
| 19分钟 | 删除第46页，2人×8分钟＋3分钟总结 |
| 12分钟 | 1人8分钟＋4分钟总结和全员V0.2 |

时间缩短时，优先减少人数，不压缩单人的结论与双验证任务。

### 3. 不能现场填写PPT时

- PPT保持空白诊断画布；
- 老师在白板按A—F六区记录；
- 助教拍照或课后整理；
- 不把含真实身份的信息上传到公开资料。
