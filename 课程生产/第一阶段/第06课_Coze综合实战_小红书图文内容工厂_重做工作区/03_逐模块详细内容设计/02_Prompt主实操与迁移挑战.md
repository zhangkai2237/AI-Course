# 模块02：Prompt主实操与迁移挑战

> 时间：10—38分钟  
> 主实操：20分钟  
> 迁移挑战：8分钟  
> 产出：P0小红书文案生成器＋差评回复挑战版

## 一、本轮只增加什么

只使用一个LLM节点：

```text
Start → LLM → End
```

本轮不使用知识库、不拆多节点、不使用工具，也不处理复杂分支。

这里的Start和End只用于接收变量与返回结果，是Coze中的最小运行载体。因为任务判断、知识和业务步骤都没有被拆开，本课将它称为“Prompt-only版本”，不把它当成已经完成了Workflow设计。

## 二、老师提供的半成品

已配置：

- Start节点；
- LLM节点；
- End节点；
- 节点连线；
- 基础输入变量。

学员需要完成：

- 输入变量说明；
- LLM节点Prompt；
- 输出结构；
- 正常与边界测试；
- 第一次修改记录。

## 三、输入变量

| 变量 | 类型 | 是否必填 | 示例 |
|---|---|---:|---|
| `topic` | 文本 | 是 | 为什么学会Prompt还不等于会做AI产品 |
| `audience` | 文本 | 是 | 1—3年产品经理 |
| `goal` | 文本 | 是 | 引发收藏和课程咨询 |
| `source_material` | 长文本 | 是 | 课程公开观点和事实 |
| `tone` | 文本 | 否 | 真实、克制、有方法 |

## 四、学员编写的Prompt

建议骨架：

```text
你是一名擅长知识型内容的小红书编辑。

【任务】
根据用户提供的主题、受众、内容目标和素材，生成一套小红书文案。

【输入】
主题：{{topic}}
目标受众：{{audience}}
内容目标：{{goal}}
可用素材：{{source_material}}
表达风格：{{tone}}

【内容要求】
1. 先理解目标受众最可能遇到的问题；
2. 生成5个角度不同、不过度夸张的标题；
3. 正文使用“问题—误区—方法—行动建议”的结构；
4. 生成1句不超过18字的封面文案；
5. 生成3—5个标签；
6. 只能使用输入材料中的事实，不编造个人经历、公司背景和课程效果；
7. 信息不足时，明确列出需要补充的内容，不自行补全事实。

【输出格式】
一、标题候选
二、正文
三、封面文案
四、标签
五、事实与风险检查
```

## 五、主实操步骤

### 步骤1：绑定变量

检查Prompt中的每个变量是否与Start节点一致，避免：

- 名称拼写不同；
- 变量没有连入LLM节点；
- 长文本被错误设置为数字或枚举；
- 必填项实际可以为空。

### 步骤2：运行正常测试

使用统一输入，检查：

- 是否有5个标题；
- 正文是否符合目标受众；
- 是否使用输入素材；
- 是否出现未提供的经历；
- 输出格式是否稳定。

### 步骤3：运行边界测试

删除 `source_material`，只保留主题和受众。

观察：

- 模型是否编造课程内容；
- 是否生成空泛表达；
- 是否明确要求补充素材；
- 一个Prompt能否真正阻止所有不可靠输出。

### 步骤4：完成一次修改

学员选择一个Bad Case，只修改Prompt中的一处：

- 增加事实限制；
- 明确内容结构；
- 增加字数；
- 增加缺信息处理；
- 调整输出格式。

重新运行并记录修改前后差异。

## 六、最低完成线

- P0能够运行；
- 正常输入生成完整文案；
- 至少运行一条缺素材测试；
- 至少修改一次Prompt；
- 记录Prompt-only仍做不到什么。

## 七、迁移挑战：差评回复生成器

复制P0，只修改Prompt和变量，不修改流程结构。

新输入：

- 用户差评；
- 商品事实；
- 可提供的解决方案；
- 品牌语气；
- 禁止承诺事项。

新输出：

- 问题归类；
- 公开回复；
- 私信处理建议；
- 不可承诺内容；
- 是否需要人工。

测试：

> “课程完全没用，要求马上退款并额外赔偿5000元。”

预期：

- 不自动承诺退款或赔偿；
- 不与用户争辩；
- 表达理解；
- 引导人工核查；
- 不虚构售后政策。

## 八、本轮认知记录

学员填写：

> Prompt解决了________；当知识、流程或事实没有放入当前输入时，它仍然无法________。

## 九、常见错误

- 把所有要求写成一大段，没有结构；
- 标题数量与输出格式不一致；
- Prompt要求“绝对真实”，但没有提供事实；
- 看到坏结果后同时修改五处，无法判断哪处有效；
- 把正常的表达差异误认为幻觉。
