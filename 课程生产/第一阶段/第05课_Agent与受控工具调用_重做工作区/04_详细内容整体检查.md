# 第05课详细内容整体检查

## 一、检查结论

当前 `01_知识点来源溯源表.md`、`02_内容结构与时间分配.md` 与 `03_逐模块详细内容设计` 已经可以作为后续老师版讲义、学生版讲义、课堂材料和 PPT 的统一生产基线。

结论：通过，但后续生产必须继续遵守本文件中的统一口径。

## 二、已修正的问题

### 1. 课时总量不真实

原始方案名义上接近 120 分钟，但模块内容、练习和演示无法在 120 分钟内完成。

现统一为：

- 基准版：138 分钟，包含 5 分钟休息；
- 紧凑版：125—130 分钟；
- 互动充分版：140—150 分钟。

用户允许课堂略微超时，因此正式材料按 138 分钟基准版展开。

### 2. 模块职责重复

“为什么需要 Agent”和“Agent、Chatbot、Workflow 的区别”容易反复解释同一件事。

现处理为：

- 模块 1 用任务路径变化解释为什么需要 Agent，并完成形态边界；
- 模块 2 只讲 Agent 的最小运行循环；
- 后续模块不再重复讲定义。

### 3. 工具数量和路径不一致

曾经存在“查询同区域参考门店”的分支，但课程没有对应工具。

现统一为三个工具：

1. `query_store_metrics`
2. `search_activity_rules`
3. `create_campaign_draft`

删除所有未定义工具和参考门店分支。

### 4. 工具参数命名不一致

模块之间曾混用 `date_range`、`focus_metric`、中文参数名等表达。

现统一为：

#### `query_store_metrics`

- `store_id`
- `start_date`
- `end_date`
- `metrics`

#### `search_activity_rules`

- `store_id`
- `rule_type`
- `query_date`

#### `create_campaign_draft`

- `store_id`
- `activity_type`
- `target_segment`
- `offer`
- `threshold`
- `start_date`
- `end_date`
- `budget_limit`
- `user_confirmed`

后续讲义、PPT、练习纸和 Coze 配置不得自行修改参数名。

### 5. T3 测试目的不一致

总结构中的 T3 用于证明“工具结果会改变 Agent 的后续路径”，详细演示稿一度写成预算风险测试。

现统一为：

> 新客基本正常、补贴异常 → 不走拉新活动路径 → 查询补贴规则 → 输出优化建议 → 不创建活动草稿。

预算和高风险确认在模块 6 及 T5 中覆盖。

### 6. 模型自行判断业务阈值

如果直接让模型判断“下降多少属于异常”，会把业务规则与模型推断混在一起。

现统一为：

- 模拟数据工具返回 `diagnosis_label`；
- 同时返回 `diagnosis_reason`；
- 阈值由确定性教学规则产生；
- Agent 负责解释和选择下一步，不自行定义异常阈值。

### 7. MCP 与 Multi-Agent 比重过大

两者均有吸引力，但不是零基础学员本课必须完成的操作。

现统一为 10 分钟概念延伸：

- Function Calling：结构化表达工具与参数；
- MCP：标准化连接外部能力；
- Multi-Agent：复杂任务中的角色协作；
- 不安装 MCP Server；
- 不搭建 Multi-Agent；
- 默认先用单 Agent 加少量工具完成最小闭环。

## 五、前后课程边界检查

### 本课负责

- Agent 与 Workflow 的关键差异；
- Agent 最小运行循环；
- Function Calling 和工具产品设计；
- 动态路径；
- 最低限度的确认、异常、停止和接管；
- Coze 最小闭环；
- MCP、Multi-Agent 的概念地图。

### 本课不负责

- 完整 API、JSON Schema 和鉴权开发；
- 长期记忆、复杂规划算法；
- 企业级权限与安全治理；
- 完整 Agent 评测体系；
- MCP 安装与 Server 开发；
- Multi-Agent 系统搭建。

### 后续承接

- 第 6 课：场景选择与 MVP 判断；
- 第 7 课：PRD 和交互设计；
- 第 9 课：评测、Bad Case 和迭代；
- 第 10 课：安全、权限、审计、回滚和人机协作；
- 第二阶段：按项目需要实践 MCP 或 Multi-Agent。

检查结果：没有替后续课程讲完，也不会让本课变成纯概念课。

## 八、后续正式生产统一规则

1. 以 `01`、`02`、`03` 和本检查文件为唯一内容基线；
2. 老师版讲义可以展开解释，但不能新增没有来源或未标记为课程设计的核心知识；
3. PPT 只做课堂信息呈现，不重新发明课程结构；
4. 学生版讲义保留关键定义、案例、练习和作业，不泄露老师参考答案；
5. 课堂材料中的工具名、参数、返回字段和测试编号必须完全一致；
6. 任何新增内容先更新来源或标记为课程设计，再同步到其他正式材料。
