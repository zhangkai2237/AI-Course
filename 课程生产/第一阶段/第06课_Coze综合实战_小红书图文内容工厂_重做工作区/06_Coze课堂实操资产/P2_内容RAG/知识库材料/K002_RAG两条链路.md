# K002｜RAG的离线建库与在线问答

文档类型：课程知识  
主题：离线建库、在线问答、问题定位  
版本：课堂版V1.0  

## 离线建库

离线建库通常在用户提问前完成：

```text
知识采集
→ 文档解析与清洗
→ 分块
→ 补充元数据
→ 向量化或建立索引
→ 可检索知识库
```

知识采集应从目标问题反推权威材料，而不是把组织里的所有文件全部上传。

解析与清洗需要检查扫描文字、表格关系、页眉页脚噪音和失效标记。

分块是把长文档切成可检索片段，片段需要尽量保留完整条件、结论和必要上下文。

元数据包括文档名、版本、生效时间、适用范围、权限和来源。

## 在线问答

在线问答在收到用户问题后发生：

```text
用户问题
→ 问题理解或改写
→ 选择知识源
→ 检索
→ 重排
→ 增强Prompt
→ 生成
→ 引用、拒答或转人工
```

检索负责找到可能相关的候选片段，候选片段不是最终答案。

重排把更符合当前问题的片段放在前面，减少无关内容干扰。

增强Prompt把用户问题、检索片段、回答规则和输出格式组合后交给模型。

模型负责组织答案，产品还需要决定引用、无答案、冲突、权限和人工处理方式。

## 常见问题定位

- 正确规则根本不存在：检查知识采集和更新；
- 文档有规则但片段不完整：检查解析和分块；
- 找到旧版但没找到新版：检查检索和版本过滤；
- 找对片段但答案仍错误：检查Prompt和生成阶段。
