# 05 纸面练习V0.1（50—58分钟）

## 任务

不打开任何平台，用八分钟画出“商家咨询分流助手”的最小流程。必须包含：

- 一个输入；
- 一个分类动作；
- 四条路径；
- 每条路径的处理方式；
- 一个最终输出；
- 至少两个明确的禁止事项。

## 学员步骤

1. 个人画图4分钟；
2. 两人互查2分钟：对方能否只看图说明路径；
3. 老师公布参考图并纠错2分钟。

## 参考结构

```text
开始：user_query
  ↓
AI分类：issue_type
  ↓
条件分支
  ├─ RULE → 按课堂规则卡回答
  ├─ DATA → 提示需查询业务系统，不生成数值
  ├─ COMPLAINT → 转人工，不承诺退款赔偿
  └─ OTHER → 追问一个澄清问题
  ↓
结束：结构化结果＋用户话术
```

## 验收点

- 四类是否互斥且有兜底；
- 处理动作是否与类型匹配；
- 是否把分类结果作为分支条件；
- 是否明确数据与投诉边界。

## 教学意图

先验证产品逻辑，再验证工具操作。学员即使没有平台账号，也能完成本课最核心的设计产出。
