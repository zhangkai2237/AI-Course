# 第05课学生版讲义使用说明

> 课程名称：《Agent与受控工具调用》  
> 适用对象：第一次系统学习Agent的初级产品经理  
> 使用方式：课前浏览、课堂记录、课后复习与完成作业

## 你将在这节课完成什么

学完本课，你应该能够：

1. 区分Chatbot、Workflow与Agent；
2. 用一个最小循环解释Agent如何完成任务；
3. 理解Function Calling在工具调用中的作用；
4. 从产品角度定义工具的输入、输出、权限和异常；
5. 为Agent设计确认点、停止条件与人工接管；
6. 用五类测试初步验证Agent方案；
7. 判断一个方案是否真的需要MCP或Multi-Agent。

## 如何使用

- 课堂上重点完成标有“请填写”的部分；
- 不必背诵工具字段，重点理解为什么需要这些字段；
- Coze演示时记录工具、参数、结果和下一步，不只看最终回答；
- 课后把课堂方案扩展为自己的Agent设计V1.0。

## 隐私提醒

- 不在课堂材料中填写真实客户信息；
- 不上传公司账号、Token、密钥或内部接口；
- 业务数据应脱敏或替换为模拟数据；
- 不把受限内部材料直接提交给公共模型。
