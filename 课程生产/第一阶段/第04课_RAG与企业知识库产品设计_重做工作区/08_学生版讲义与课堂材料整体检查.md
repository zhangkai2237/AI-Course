# 第04课学生版讲义与课堂材料整体检查

## 检查结论

学生版讲义、老师版讲义、课堂材料和详细内容设计已经对齐，可以进入PPT结构生产。

## 检查结果

| 检查项 | 结果 | 说明 |
|---|---|---|
| 模块结构 | 通过 | 学生版01-09与老师版和时间结构一致 |
| 核心概念 | 通过 | 定义、双链路、治理、分块、检索、重排均有解释 |
| 产品边界 | 通过 | 知识走RAG、实时事实走业务系统、高风险走人工 |
| 幻觉表述 | 通过 | 明确RAG只能缓解，不能消除 |
| 测试方法 | 通过 | 先写预期、先看检索、再看生成 |
| 答案隔离 | 通过 | 学生版不含T1-T5的具体日期答案和完整修正答案 |
| 课堂记录 | 通过 | 保留判断表、知识治理表、分段记录和Bad Case记录 |
| 作业接口 | 通过 | 指向独立作业模板，不重复维护两份答案 |
| 零基础适配 | 通过 | 不要求编程、公式或平台注册 |
| 隐私安全 | 通过 | 未出现讲师当前任职或当前业务信息 |

## 四套材料的分工

- 详细内容设计：定义课程逻辑和教学边界；
- 老师版讲义：提供讲法、时间、追问和故障兜底；
- 学生版讲义：提供概念、结构和课堂记录空间；
- 课堂材料：提供可导入文档、测试题、答案和作业模板。

## Review中确认的关键一致性

1. V2是当前有效知识，V1只用于版本冲突；
2. T3只针对当前活动判断，不把结论扩大到其他活动；
3. T4实时补贴不通过RAG回答；
4. T5优先治理版本，无法确认时暴露冲突；
5. 学生版不会提前看到老师参考答案；
6. 平台失败时仍可用纸面检索卡完成课程。

## 进入PPT前必须保留

PPT结构中至少需要出现：

1. 上一课四路Workflow及`RULE`升级点；
2. RAG适合与不适合对比；
3. 离线建库和在线问答双链路；
4. 知识治理六字段；
5. 分块错误示例；
6. 纸面V0.1；
7. 平台操作检查点；
8. 五条测试；
9. 四步排查；
10. 作业与下一课接口。

## 最终判断

学生版不是老师讲义的删减稿，而是一份可以课前预习、课堂记录和课后复习的独立材料。当前版本既保留足够解释，也没有提前泄露课堂Bad Case答案。
