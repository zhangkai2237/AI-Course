# 商品对比工具一期产品决策摘要

> 用途：第八课第一部分课堂找错。判断 AI 初版 Demo 时，以本表为依据。

| 主题 | 已确认的一期决策 |
|---|---|
| 一期品类 | 手机 |
| 类目范围 | 只支持同一三级类目 |
| 对比对象 | 具体 SKU |
| 商品数量 | 同时对比 2 至 4 个 |
| 未登录使用 | 支持 |
| 保存方式 | 仅本地临时保存 |
| 默认视图 | 默认展示核心参数并突出差异；“只看差异”默认关闭，可由用户开启 |
| 全部参数 | 支持展开 |
| 价格 | 展示活动价与优惠条件，不承诺统一到手价 |
| 参数缺失 | 显示“暂无数据”，不得推测 |
| 参数冲突 | 标注来源并提供反馈入口 |
| AI 推荐 | 一期不做 |

## 一期明确不做

- 跨品类对比；
- AI 推荐最佳商品；
- 跨设备历史记录；
- 强制登录；
- 无依据补全参数；
- 对所有用户承诺统一到手价。
