# Token与上下文分类练习｜老师参考答案

> 仅供老师备课和课堂讲评，不发给学员。分类不是唯一答案，重点是能否说明它服务哪项目标输出。

## 一、参考分类

- 本次转写：通常必须；
- 客户资料和商机阶段：通常按任务需要由系统带入；
- 产品方案：分析异议对象时按需提供；
- 全部CRM记录：不应默认全部提供，应筛选相关记录；
- 公司所有资料：本次暂不需要，且可能带来噪声、冲突、权限和容量问题。

## 二、追加判断参考

1. 能够放入上下文，不代表应该全部放入；还要判断相关性、可靠性、权限、版本和成本。
2. 资料冲突时，至少要标明来源和时间，规定优先级；无法判断时交给用户确认。
3. 重要信息没有进入本次上下文时，模型不能保证使用它。

核心结论：

> 上下文窗口回答最多能装多少，上下文设计回答当前应该装什么。
