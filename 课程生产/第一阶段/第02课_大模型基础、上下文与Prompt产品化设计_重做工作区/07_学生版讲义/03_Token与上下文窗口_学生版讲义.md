# 模块03：Token与上下文窗口

> 课堂时间：25—40分钟  
> 本模块任务：理解模型本次处理信息的基本单位和容量边界

## 一、Token是什么

Token是模型处理和生成信息时使用的基本单位。

为了处理文本，模型会通过对应的tokenizer把文本转换为Token序列。

### Token不固定等于什么

Token不固定等于：

- 一个汉字；
- 一个中文词；
- 一个英文单词；
- 一个标点；
- 一个固定长度的字符。

不同模型的词表和切分方式可能不同。同一句话在不同模型中，Token数量也可能不同。

不要把某个课程、网站或模型给出的换算当作通用公式。

## 二、为什么产品经理需要知道Token

### 1. 影响容量

模型一次能够处理的上下文存在容量限制。输入内容越多，占用的Token通常越多。

### 2. 影响输出空间

模型生成回答也会产生Token。如果输入已经占用大量空间，留给输出的空间可能减少，具体行为取决于模型和产品实现。

### 3. 可能影响成本

商业API通常根据输入和输出用量计费。产品经理本课不做成本核算，但需要知道：

- 长Prompt不是免费空间；
- 长历史对话会持续占用用量；
- 无关材料可能干扰结果并增加成本。

## 三、哪些内容会涉及Token

一次大模型调用可能包含：

- 产品内部指令；
- 用户本次输入；
- 历史对话；
- 上传文档；
- 系统补充的业务材料；
- 检索到的知识片段；
- 模型本次输出。

界面中看不到的内部指令，也可能属于模型本次得到的上下文。

## 四、上下文窗口是什么

可以把上下文窗口理解为：

> 模型完成本次任务时能够使用的有限信息工作区。

| 内容 | 例子 |
|---|---|
| 产品内部指令 | 角色、业务规则、输出结构 |
| 用户输入 | 本次问题和特殊说明 |
| 历史对话 | 之前保留的多轮消息 |
| 外部材料 | 上传文件、转写、知识片段 |
| 业务数据 | 客户资料、订单、商机阶段 |
| 模型输出空间 | 本次需要生成的回答 |

## 五、上下文窗口不是什么

### 1. 不等于永久记忆

产品保存了历史记录，不代表每次调用都把全部历史发送给模型。

### 2. 不等于模型训练时学过的全部知识

模型训练中学到的能力和知识，与当前这一次实际获得的上下文不是同一个概念。

### 3. 不等于产品数据库

数据保存在CRM或数据库里，不代表模型本次已经获得这些数据。产品需要决定是否查询、筛选和提供。

## 六、信息太多会怎样

### 1. 容量问题

当输入和预期输出超过模型或产品允许的上下文长度时，可能出现：

- 无法提交；
- 内容被截断；
- 早期信息被移除；
- 输出空间不足；
- 产品先进行摘要或压缩。

具体行为取决于模型和产品实现，不能一概而论。

### 2. 质量问题

即使没有超过容量，也可能因为以下原因降低效果：

- 无关信息太多；
- 同一事实存在多个版本；
- 新旧制度冲突；
- 重要信息埋得太深；
- 材料没有来源和时间；
- 任务本身太复杂。

所以：

> 能放进去和能稳定使用，是两件事。

## 七、上下文窗口和上下文设计

| 概念 | 回答的问题 |
|---|---|
| 上下文窗口 | 最多能装多少 |
| 上下文设计 | 当前应该装什么 |

对产品经理，第二个问题更重要。

需要判断：

1. 哪些信息是完成任务必需的？
2. 哪些规则应由产品固定提供？
3. 哪些信息可以从系统自动获取？
4. 哪些历史内容需要保留、压缩或重新获取？
5. 哪些材料与当前任务无关？

## 八、销售拜访助手示例

### 通常必要

- 本次拜访转写；
- 说话人标签；
- CRM字段定义；
- 缺失信息处理规则。

### 可能按需

- 客户基本资料；
- 当前商机阶段；
- 本次讨论的产品方案；
- 与当前异议相关的制度。

### 不应默认全部提供

- 客户全部历史记录；
- 公司所有制度和产品资料；
- 与本次任务无关的聊天；
- 无法确认新旧版本的材料。

## 九、常见误区

### “上下文越长，效果一定越好”

不成立。更多信息可能带来噪声、冲突、权限和成本问题。

### “产品保存了信息，模型就一定记得”

不成立。要看产品是否把相关信息放入本次上下文。

### “一个Token固定等于一个汉字”

不成立。具体切分依赖目标模型的tokenizer。

### “把公司所有资料放进去就不需要其他知识机制”

不一定。企业知识可能规模大、频繁更新并存在权限差异，后续还要评估检索和数据连接方式。

## 十、先记住

1. Token是模型处理和生成信息的基本单位；
2. Token不固定等于一个字或一个词；
3. 上下文窗口是本次任务的有限信息空间；
4. 上下文既有容量问题，也有质量问题；
5. 产品经理要围绕目标输出选择必要信息。
