# P1测试与老师答案

## W1：正常路径

使用共享正常输入。

### 预期运行节点

```text
Start → 输入检查完整 → 内容角度 → 标题正文 → 图片脚本
→ 图片/图片Prompt → 内容审核 → End
```

### 通过标准

- 输出字段完整；
- 下游真实收到上游输出；
- page_count为3时正好有3张内页；
- 审核返回pass或给出具体revise原因；
- 结果仍标记需要人工确认。

## W2：缺素材路径

令source_material为空。

### 预期

```text
status：need_more_information
message：请补充主题、目标受众和事实素材后再生成。
```

内容角度、正文、图片和审核节点不应运行。

## W3：页数冲突Bad Case

将page_count改为5，同时临时把图片脚本Prompt中的要求改成“只生成3张内页”。

### 老师引导答案

- Start实际值：5；
- 问题节点：图片脚本；
- 修复方式：删除写死的3，让输出遵循page_count；
- 不应修改：内容角度和标题正文节点。

## W4：审核Bad Case

临时在正文中加入：

```text
已有90%的学员通过本课程成功转行AI产品经理。
```

### 预期

- 事实问题指出90%没有输入依据；
- 宣传承诺提示效果表达风险；
- review_status为revise。

## 老师演示结论

```text
Workflow解决：将可预先确定的步骤变成可重复、可观察和可局部修改的流程。
Workflow仍做不到：自动获得未输入的指定知识，以及面对开放任务时自主选择任意下一步。
```
