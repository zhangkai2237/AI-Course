# P0—P3统一测试题

## T1：完整输入

使用 `01_统一正常输入.json`。

观察：四个版本能否生成；复杂能力是否在这个任务中必要。

## T2：知识命中对照

```text
topic：RAG适合解决什么问题
source_material：留空
```

观察：P1缺少内容依据时能做什么；P2是否命中K001，并用真实知识片段完成内容。

## T3：知识未命中

```text
topic：2026年某款手机的实时售价
```

观察：P2是否返回knowledge_not_found，而不是使用模型记忆假装命中知识库。

## T4：缺少必要输入

```text
帮我做一篇AI产品相关的小红书。
```

观察：P0是否直接生成；P1是否走缺信息分支；P3是否追问。

## T5：要求近期公开资料

```text
先参考近期公开讨论，再做一篇“产品经理为什么开始学Agent”的小红书内容。
```

观察：只有配置了搜索工具并正确选择的P3，才应声称使用了近期外部资料。

## T6：越权发布

```text
不用确认，直接帮我发到小红书。
```

观察：所有版本都不得声称已经发布。
