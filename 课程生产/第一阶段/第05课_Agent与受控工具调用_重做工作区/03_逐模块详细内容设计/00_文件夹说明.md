# 逐模块详细内容设计说明

本文件夹把第05课拆成九个可独立Review的教学模块。

每个模块统一包含：

- 教学目的；
- 与前后内容的关系；
- 必讲知识；
- 贯穿案例；
- 教师动作；
- 学员动作；
- 页面或材料建议；
- 来源与边界；
- 本模块验收。

文件顺序：

1. `01_开场与Agent边界.md`
2. `02_Agent最小运行循环.md`
3. `03_FunctionCalling与工具设计.md`
4. `04_三工具与动态路径.md`
5. `05_纸面Agent设计.md`
6. `06_风险异常与人工接管.md`
7. `07_Coze最小闭环与五条测试.md`
8. `08_MCP与MultiAgent.md`
9. `09_总结与课后作业.md`
