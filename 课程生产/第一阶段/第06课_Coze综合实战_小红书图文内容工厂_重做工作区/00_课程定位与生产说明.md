# 第06课《Coze综合实战：从Prompt到Agent搭建小红书图文内容工厂》课程定位与生产说明

## 一、课程定位

这是一节180分钟的纯实战工作坊。

学员不再单独听Prompt、Workflow、RAG和Agent的定义，而是在Coze中围绕同一个项目连续完成四次升级：

```text
单节点Prompt生成器
→ 多节点图文Workflow
→ 检索历史文字并抽象个人语气的RAG Workflow
→ 能够动态调用Workflow的内容策划Agent
```

课程只做到Coze内部可运行，不延伸到：

- 独立网页；
- API调用；
- 登录、支付和用户体系；
- 自动发布小红书；
- 正式产品部署。

## 二、为什么使用一个连续项目

如果四种能力分别做四个无关案例，学员容易只记住操作步骤，无法理解组合关系。

本课使用“小红书图文内容工厂”贯穿：

- Prompt负责单次内容生成；
- Workflow把复杂内容生产拆成稳定节点；
- RAG检索本人历史文字并抽象表达语气，历史事实不进入新内容；
- Agent根据用户目标判断是否补充信息、查询素材、调用Workflow或保存草稿。

核心关系：

```text
Agent
└── 调用RAG版小红书Workflow
    ├── 检索历史表达样本并提取语气卡
    ├── 调用多个LLM Prompt节点
    └── 调用图片生成能力或输出图片提示词
```

## 三、目标学员

- 已完成前面Prompt、Workflow、RAG、Agent基础课程；
- 对概念有印象，但还不能独立组合；
- 能登录Coze并完成基础节点操作；
- 不要求有编程能力。

## 四、课堂最终产物

学员至少带走四个可运行产物：

1. `P0_小红书文案生成器`；
2. `P1_小红书图文Workflow`；
3. `P2_个人语气_RAG图文Workflow`；
4. `P3_小红书内容策划Agent`。

同时完成：

- 四类能力对照记录；
- 每类一个迁移挑战；
- 四版本统一测试结果；
- 一份自己的改造方向。

## 五、课堂主案例

### 内容主题

> 零基础产品经理为什么学会Prompt还不等于会做AI产品？

### 目标人群

1—3年经验、希望转向AI产品方向的产品经理。

### 内容目标

- 让用户理解AI产品能力不只包括Prompt；
- 提供清晰的学习路径；
- 引发收藏、评论或课程咨询；
- 不使用夸张承诺和未经证实的职业经历。

### 内容素材

全部使用公开或虚构材料，不包含讲师当前公司和当前业务。

## 六、四个迁移挑战

| 能力 | 主案例 | 迁移挑战 |
|---|---|---|
| Prompt | 小红书文案生成 | 差评回复生成器 |
| Workflow | 小红书图文生产 | 60秒短视频口播稿 |
| RAG | 个人语气内容生成 | 非小红书历史文字迁移测试 |
| Agent | 小红书内容策划 | 新品上市内容策划Agent |

迁移挑战只修改关键配置，不从空白重新搭建。

## 七、教学方式

每个实操模块采用统一节奏：

```text
老师展示最终效果
→ 解释本轮只增加什么
→ 学员复制半成品模板
→ 学员完成关键配置
→ 运行正常测试
→ 运行边界测试
→ 填写能力对照记录
→ 完成迁移挑战
```

不采用“老师操作、学员围观”的演示课模式。

## 八、课程准确性底线

- 不说Workflow取代Prompt；每个LLM节点仍然需要Prompt；
- 不说RAG一定让文案更有创意；RAG主要增加指定知识与事实依据；
- 不说Agent比Workflow高级；Agent增加动态判断，也增加不稳定性；
- 不把Coze按钮位置当作稳定知识；开课前必须实测当前界面；
- 不把能运行一次视为可上线产品；
- 不上传公司内部资料、客户信息、密钥或受限数据。
