# 第06课老师版讲义整体复核

> 复核范围：`05_老师版讲义`全部文件  
> 复核目标：检查讲义是否能支持零基础老师备课并完成180分钟授课

## 一、结构复核

| 项目 | 结果 | 说明 |
|---|---|---|
| 与课程定位一致 | 通过 | 全课只到Coze搭建、运行和测试 |
| 与时间结构一致 | 通过 | 10＋28＋45＋7休息＋33＋40＋12＋5＝180分钟 |
| 与详细内容一致 | 通过 | P0—P3、迁移挑战、T1—T5均已覆盖 |

| 理论与实操比例 | 通过 | 概念仅服务于当轮操作和测试 |

## 二、可授课性复核

讲义已经为每个核心模块补充：

- 老师需要先理解的概念边界；
- 可直接使用的课堂讲法；
- Coze中的操作目的和顺序；
- 学员当场动作；
- 正常、边界和失败测试；
- 预期结果；
- 常见故障和恢复方案；
- 最低完成线；
- 模块转场。

结论：老师可以依据讲义完成备课和试讲，但不能跳过课前实际搭建。平台操作类课程不存在“只看文字、不跑Demo也能稳定授课”的安全方案。

## 三、关键概念复核

### Prompt与Workflow

- P0明确说明Start和End只是最小载体；
- 没有将三节点结构误称为完整Workflow；
- P1明确Prompt负责节点行为，Workflow负责步骤协作。

### Workflow与Agent

- Workflow用于可预先确定的稳定SOP；
- Agent用于根据目标和状态动态选择下一步；
- 没有把Agent说成更高级或必然更好。

### RAG与幻觉

- 讲义要求查看实际检索片段，而非只看最终回答；
- 明确无命中不得编造个人事实；
- 明确RAG不能保证检索正确，也不能消除全部幻觉。

### 保存与发布

- `save_content_draft`被定义为课堂模拟工具；
- 保存前必须确认；
- 全课没有真实发布工具；
- A5专门验证不得谎称已发布。

## 四、隐私复核

- 未使用当前任职公司名称；
- 未使用当前业务和真实经营材料；
- 案例材料限定为公开或虚构内容；
- RAG模块加入知识库导入前检查；
- 总结模块加入最终隐私清单。

## 五、课堂风险复核

| 风险 | 已设置的处理方式 |
|---|---|
| 模型或节点名称变化 | 用功能名称和操作目的描述，不依赖单一按钮文案 |
| 图片能力不可用 | 输出结构化图片Prompt＋老师预生成图片 |
| 搜索工具不可用 | 使用模拟趋势材料Workflow |
| 学员权限或复制失败 | 结对操作、老师中间版本、截图旁听 |
| 单人排错拖堂 | 3分钟切换中间版本 |
| 知识库解析失败 | 课前解析、课堂抽查、备用片段截图 |
| Agent声称虚假成功 | 检查真实工具调用记录和失败返回 |

## 六、仍需在正式授课前完成的事项

以下内容不属于讲义文字问题，必须通过实际课堂资产完成：

1. 搭建并跑通P0—P3老师完成版；
2. 制作四个学员半成品模板；
3. 准备并脱敏老师本人历史表达样本；
4. 验证语气卡只保留表达方式，不包含历史事实；
5. 配置或模拟搜索与保存工具；
6. 按T1—T5保存老师答案和运行截图；
7. 生成《四版本能力与测试记录表》；
8. 课前一天重新跑一次全部Demo。

## 七、最终结论

老师版讲义在内容层面已经完整，可以进入“课堂素材包与Coze模板制作”阶段。正式PPT应在真实模板跑通之后生成，以便使用真实画布、节点和调用记录，而不是用抽象示意图代替实操证据。
