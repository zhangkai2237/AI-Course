## 一、项目目标

只使用一个LLM节点，根据本次提供的主题、受众、目标、事实素材和风格生成小红书文案。

本项目不使用知识库、外部搜索、图片节点、保存工具和发布能力。

## 二、画布结构

```text
Start → LLM_生成小红书文案 → End
```

Start和End仅用于接收变量与返回结果。本项目的核心能力仍是一次Prompt调用。

## 三、Start输入

| 名称 | 类型 | 必填 | 默认值/示例 |
|---|---|---:|---|
| `topic` | String | 是 | 为什么学会Prompt还不等于会做AI产品 |
| `audience` | String | 是 | 1—3年经验、希望转向AI方向的产品经理 |
| `goal` | String | 是 | 引发收藏、评论或课程咨询 |
| `source_material` | String/Long Text | 是 | 允许使用的事实和观点 |
| `tone` | String | 否 | 真实、克制、有方法，不制造焦虑 |

## 四、LLM节点

节点名称：`LLM_生成小红书文案`

将 `01_LLM节点Prompt.txt` 全部复制到Prompt区域，并通过Coze变量选择器绑定：

| Prompt占位 | 上游变量 |
|---|---|
| `{{topic}}` | `Start.topic` |
| `{{audience}}` | `Start.audience` |
| `{{goal}}` | `Start.goal` |
| `{{source_material}}` | `Start.source_material` |
| `{{tone}}` | `Start.tone` |

建议输出变量：

| 名称 | 类型 | 说明 |
|---|---|---|
| `content_package` | String | 完整结构化文案 |

如果当前Coze版本支持稳定的结构化输出，可进一步拆分为titles、body、cover_text、tags和risk_check；首次搭建优先保证一个字符串输出跑通。

## 五、End输出

| End字段 | 来源 |
|---|---|
| `result` | `LLM_生成小红书文案.content_package` |

## 六、搭建完成检查

- [ ] 五个Start变量类型正确；
