# 第 00 课试讲检查表 V2

## 内容

- [ ] 初心使用“我调研到的课程样本”，没有声称全市场无好课；
- [ ] 清楚表达“AI 产品经理不是 AI 工具产品经理”；
- [ ] 同时肯定工具的研究、表达和验证价值；
- [ ] 第一阶段强调体系化，第二阶段强调项目和小组互学，第三阶段强调求职转化；
- [ ] 说明课程可能调整，但核心目标、权益和交付稳定；
- [ ] 坦诚能力边界后，给出来源、验证、审核、勘误和更新机制；
- [ ] 没有深入讲完整五步法；
- [ ] 本地生活案例明确为公开信息与教学假设；
- [ ] 没有滴滴租车、当前公司或内部未公开信息；
- [ ] 作业和课堂练习与学习目标一致。

## 时间

- [ ] 10 分钟结束开场诊断；
- [ ] 25 分钟结束初心；
- [ ] 45 分钟结束三阶段；
- [ ] 55 分钟结束透明说明；
- [ ] 82 分钟开始课程地图；
- [ ] 100 分钟开始练习；
- [ ] 112 分钟开始总结。

## 表达

- [ ] 没有攻击具体竞品课程或老师；
- [ ] 没有“AI 最近几年才出现”等不准确表述；
- [ ] 没有“课程可能有错，请理解”等降低质量预期的话术；
- [ ] 没有就业、薪资和转型成功承诺；
- [ ] 事实、参考课观点、讲师观察和教学假设能够区分。

## 材料

- [ ] PPT 与讲师稿页码一致；
- [ ] 学员讲义不含讲师内部备课信息；
- [ ] 课堂练习可在 12 分钟内完成；
- [ ] Word、PPT 可以正常打开；
- [ ] 旧版完整五步法材料未误发给学员。
