# 当前用户流程

## 典型流程：手机购买决策

```text
搜索或进入手机频道
→ 打开商品A详情页
→ 查看价格、参数和评价
→ 返回列表页
→ 打开商品B详情页
→ 尝试记住差异
→ 截图或收藏
→ 打开商品C详情页
→ 返回商品A再次确认
→ 计算优惠
→ 选择SKU
→ 加入购物车或直接购买
```

## 当前痛点

1. 需要在多个页面之间反复切换。
2. 用户需要自己记忆或记录参数。
3. 不同商品参数名称和单位不完全一致。
4. 价格包含优惠券、会员价、以旧换新等条件，难以直接横向比较。
5. 不同SKU之间的价格和配置容易混淆。
6. 详情页参数很多，但不一定符合用户真实决策维度。

## 现有替代方案

- 浏览器多标签页
- 截图
- 备忘录或Excel
- 收藏夹
- 第三方参数网站
- 短视频或评测内容
