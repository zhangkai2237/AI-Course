## 九、自检

### 必做版

- [ ] 场景具体到谁在什么时点完成什么任务；
- [ ] 至少2项目标输出和可检查标准；
- [ ] 至少3类必要上下文；
- [ ] Prompt要求能对应任务、风险或输出；
- [ ] 区分产品固定、用户提供和系统获取；
- [ ] 至少为1项高风险结果设计建议检查或必须确认；
- [ ] 运行至少1条样例；
- [ ] 找到至少1条Bad Case；
- [ ] 提出具体修正动作；
- [ ] 没有提交敏感数据、隐私或公司机密。

### 进阶版

- [ ] 补齐完整Prompt骨架；
- [ ] 补齐主要风险字段的证据、权限和确认交互；
- [ ] 完成第二轮复测；
- [ ] 判断是否已经超出Prompt和上下文能力。
