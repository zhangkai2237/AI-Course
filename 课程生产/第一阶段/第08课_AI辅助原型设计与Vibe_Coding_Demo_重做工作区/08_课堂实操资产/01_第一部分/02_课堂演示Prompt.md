# 第一部分课堂演示 Prompt

## Prompt A：直接生成 Demo

> 用于制造第一轮结果。它故意只给出宽泛要求，帮助学员观察 AI 会如何补全设计空白。

```text
请阅读项目中的商品对比工具PRD，生成一个完整、专业、适合移动端展示的商品对比工具Demo。

要求功能完整、交互流畅、视觉效果好，可以直接用于课堂演示。
```

课堂使用时，不需要讨论怎样润色这条 Prompt。重点是检查生成结果是否忠于正式产品决策。

## Prompt B：对照正式决策审查初版 Demo

> 学员完成第一轮人工找错后再使用，用来比较人工判断与 AI 审查结果。

```text
请读取以下正式依据：
1. 商品对比工具最终PRD；
2. 产品决策记录；
3. 第七课产品决策摘要；
4. 当前Demo的页面、代码和模拟数据。

请审查当前Demo，不要直接修改。

重点检查：
- 是否新增了PRD没有确认的功能；
- 是否违反商品范围、SKU、数量、价格、参数缺失和参数冲突规则；
- 是否遗漏关键边界与异常状态；
- 是否把模拟数据或前端效果表达成真实能力。

只输出问题清单，每条包含：
1. 页面或位置；
2. 问题描述；
3. 对应PRD或产品决策；
4. 不处理的影响。

如果没有明确依据，请标记“需要产品经理判断”，不要自行新增需求，也不要修改代码。
```
