## 一、项目目标

让Agent根据用户目标和当前信息决定：

- 信息不足时先追问；
- 用户明确需要近期公开资料时才搜索；
- 需要完整图文时调用P2；
- 展示内容后，只有确认才保存课堂模拟草稿；
- 没有发布能力时拒绝声称已经发布；
- 工具失败时如实说明。

## 二、Agent结构

```text
用户请求
→ Agent检查目标与必要信息
   ├─ 缺信息 → 追问
   ├─ 需要近期资料 → search_topic_material
   ├─ 需要完整图文 → run_xhs_rag_workflow
   ├─ 明确确认保存 → save_content_draft
   └─ 完成/取消/越权 → Stop
```

## 三、Agent指令

将 `01_Agent系统指令.txt` 完整复制到Agent指令区域。

## 四、工具1：run_xhs_rag_workflow

来源：已经跑通的P2 Workflow。

### 工具说明

```text
当用户需要一套完整小红书图文，且主题、受众和目标已经明确时使用。用户事实素材可以为空，由P2尝试命中课堂课程知识库。
工具内部会根据topic检索课堂课程知识，把真实命中片段整理成证据，再结合用户素材生成标题正文与图片脚本，最后完成事实与引用初审。
用户只要选题、信息不完整或尚未要求生成完整内容时不要调用。
```

### 参数映射

| 工具参数 | 来源 |
|---|---|
| `topic` | 用户主题 |
| `audience` | 用户明确提供或追问得到 |
| `goal` | 用户内容目标 |
| `source_material` | 用户额外素材＋必要时的搜索结果；可为空，知识库命中也是允许的事实来源 |
| `target_format` | 默认“小红书知识图文” |
| `tone_hint` | 用户额外语气要求；未指定时为空 |
| `image_style` | 用户风格；未指定时使用课堂默认值 |
| `page_count` | 未指定时为3 |

## 五、工具2：search_topic_material

优先使用授课空间中已实测可用的公开搜索工具。工具说明使用 `02_工具定义.json` 中内容。

如果课堂搜索权限不稳定，使用 `04_模拟搜索工具Prompt.txt` 和 `03_模拟近期材料.md` 搭建一个模拟搜索Workflow。必须向学员说明它验证的是“Agent何时搜索和怎样传递结果”，不是验证真实互联网搜索质量。

## 六、工具3：save_content_draft

本工具只保存课堂模拟草稿，不连接真实内容系统。

可使用 `05_模拟保存工具Prompt.txt` 搭建最小Workflow：

```text
Start(title, content, confirmed)
→ IF confirmed是否为true
   ├─ false → End(status=confirmation_required)
   └─ true → LLM_生成课堂保存回执
             → End(status, draft_id, saved_title, notice)
```

此工具没有发布能力，工具说明中必须明确保存不等于发布。

## 七、工具接入检查

- [ ] 三个工具名称和职责不同；
- [ ] P2参数名称与新版内容RAG的Start一致；
- [ ] 搜索工具写明“不适用条件”；
- [ ] 保存工具必须接收confirmed；
- [ ] 保存失败时有结构化失败返回；
- [ ] 工具列表中没有publish、post或真实发布工具。
