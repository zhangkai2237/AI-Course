# 第二次课 · 审核链路课堂Demo v1.0

这是本地课堂演示应用，沿用净小伴P1营销审核案例。默认运行本地规则，不调用真实模型。商品、资料、人员与审批动作均为教学设定；只覆盖R01功能对象、R02价格条件和R03赠品权益，不执行真实发布。

## 怎么打开

- **立即演示**：打开 `index.html`，无需安装依赖；支持自检、正式审核、链路查看、资料配置、巡检、测试与导出。浏览器需允许JavaScript。
- **接真实模型**：双击 `启动课堂Demo.command`（需要Python 3），自动打开 `http://127.0.0.1:8791`。点右上角“模型连接”，填写兼容Chat Completions的基础地址、模型ID、API Key，保存后将运行模式切为“真实模型调用”。
- 接口基础地址例如 `https://你的服务/v1`，程序会追加 `/chat/completions`；也可以填写完整端点。服务支持JSON模式时再勾选json_object。
- 如浏览器无法保存进度，使用“导出记录”备份。不同浏览器、file页面与本地服务页面的记录可能分别保存。

真实调用会向你选择的模型服务发送本次文案、审核点与有效业务资料。密钥仅留在本机服务进程内存，关闭服务即清除，不放入HTML、本地存储、日志或导出记录。未配置、接口报错、超时、无效JSON、原句和引用校验失败均显示为未完成，不自动退回模拟结果。接口适配已用模拟HTTP响应测试；本次未提供真实凭证，尚未完成外部模型联调。

## 六个页面做什么

| 页面 | 用途 |
|---|---|
| 内容与自检 | 编辑文案、关联商品活动日期、保存版本、检查、正式提交。 |
| 正式审核 | 查看提交正文和证据；确认问题、不成立留理由、人工补核、退回、复核、通过。 |
| 链路实验室 | 展开每次运行的任务快照、所用资料、审核配置、输出、程序校验及交接。 |
| 资料与审核点 | 按角色调整资料可用性、有效期、审核说明与启停，变更后保留新版本。 |
| 历史内容巡检 | 业务变化后检查在用内容，保留范围待核项，认领、修订、复核并核验实际使用更新。 |
| 测试与迭代 | 运行8条课堂样例、对照教学参考，记录Bad Case、修改与复测。 |

## 推荐课堂演示顺序（约12—15分钟）

1. **完整看一遍**：作者在“内容与自检”运行问题稿，观察三项问题，展开依据和定位原句。
2. **改一个条件**：载入“只补会员资格”重新检查；R02仍会提示两类券及使用条件未完整。
3. **完成一次复核**：载入“条件完整稿”检查并正式提交。右上角切审核员，记录正式通过理由。返回作者改稿时，旧通过不对应新版。
4. **拆解审核链**：进入“链路实验室”，按六步展开本次输入输出。运行模式会明确标示模拟或真实。
5. **看异常**：“课堂控制”可设资料缺失、超时、原句校验失败。选择“旧版本结果迟到”场景，检查进行中保存新稿，观察结果仍关联旧稿。
6. **看巡检闭环**：“课堂控制”载入“名额用完后的巡检”，由内容负责人发起。C01待处理；C03已有变化说明；C05无赠品主张；C06保持范围待核；停用及其他活动内容不能被误纳入。
7. **走到实际更新**：认领C01、创建修订稿，作者检查提交，审核员正式复核，最后内容负责人回巡检页登记实际位置与使用版本。仅内部改稿不会自动关闭问题。
8. **看一个Bad Case**：运行教学样例；T08使用中文价格和自由改写，固定规则可能当作不适用，与“应交人确认”的参考不一致，用于讨论规则覆盖缺口。记录修改方案并复测，不把8条样例当作验收结论。

## 边界与状态

- 第一版是审核提效，正式决定由课堂角色模拟；页面角色切换不是生产身份认证与权限系统。
- 本地规则是确定性的有限表达匹配。审核说明的自由编辑仅进入真实模型输入，不改变本地语义匹配代码。正常命中也不代表整篇合规。
- 预置资料支持P1标准版 / P1十月活动 / 2026年10月适用日期；选择其他活动、规格或有效期外的日期会出现资料缺失。
- 检查快照固定正文、规则和资料；正文、上下文或配置变化后不可直接复用。对无法确定依赖的变更采用整条检查重跑。
- 资料、配置、人工处理与历史检查保留在当前浏览器；导出JSON不含密钥。载入课堂场景或重置会清空当前演示进度。
- 暂未连接真实发布平台、订单系统、企业权限或持久数据库。巡检“实际更新”由课堂角色登记核验，不会改动外部内容。
