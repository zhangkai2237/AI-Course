# 07 搭建最小知识库

## 课堂目标

操作重点不是记住按钮，而是观察：

1. 文档如何被解析和分块；
2. 问题检索到了什么；
3. 检索内容如何进入回答；
4. 无依据和冲突怎样处理。

## 最小操作链路

```text
创建教学知识库
→ 导入当前有效文档
→ 查看解析和分段
→ 单独测试检索
→ 接入RULE分支
→ 配置回答约束
→ 运行正常问题
```

## 导入文档时

课堂初始只导入：

- 新客立减活动规则V2；
- 活动违规与申诉说明V1。

失效V1将在后续测试中由老师加入，用于观察版本冲突。

## 查看分段

记录：

- 抽查文档：________________
- 标题是否保留：____________
- 日期和适用范围是否完整：____
- 发现的问题：______________

## 单独测试检索

问题：

> 新客活动到什么时候还能报名？

先不看最终回答，记录：

- 检索文档：________________
- 检索片段：________________
- 是否包含正确日期：________
- 是否包含适用范围：________
- 是否混入无关内容：________

## 接入RULE

```text
RULE问题
→ 用用户问题检索指定知识库
→ 将候选片段交给回答节点
→ 按规则生成
```

回答应保留：

- 简洁答案；
- 适用条件；
- 文档和版本；
- 无依据或冲突提示。

## 安全边界

- 不上传真实工作材料；
- 不上传客户或账户信息；
- 不把课堂Demo当成可上线系统；
- 平台入口变化时关注同类能力，不死记按钮。
