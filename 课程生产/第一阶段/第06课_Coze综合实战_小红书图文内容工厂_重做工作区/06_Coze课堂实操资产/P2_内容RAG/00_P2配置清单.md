# P2内容知识RAG图文Workflow｜Coze配置清单

> 当前版本：V1.0（2026-08-02）  
> 本版本不学习个人语气，只检索与当前主题相关的知识内容。

## 一、课堂目标

在P1固定Workflow上增加知识库，让学员观察：

- P1只能使用本次输入素材；
- P2可以根据topic命中知识库内容；
- 命中内容进入策划和写作节点，成为可追溯的事实依据；
- 没命中时不能假装知识库支持答案；
- RAG解决的是外部知识接入，不是个人语气模仿。

## 二、课堂知识库

知识库名称建议：`AI产品经理课程知识库_课堂版`

上传：

- `知识库材料/K001_RAG解决什么与不解决什么.md`
- `知识库材料/K002_RAG两条链路.md`

文档解析完成后，先在知识库测试页分别搜索：

```text
RAG适合解决什么问题
RAG为什么不能完全消除幻觉
RAG离线建库和在线问答有什么区别
```

## 三、目标画布

```text
Start
→ IF_必要输入检查
   ├─ 缺失 → End_补充信息
   └─ 完整 → Knowledge_按主题检索课程知识
             → IF_知识是否命中
                ├─ 无命中 → End_知识未命中
                └─ 有命中 → LLM_整理知识证据
                              → LLM_知识增强内容策划
                              → LLM_知识增强标题正文
                              → LLM_图片脚本（沿用P1）
                              → 图片生成/图片Prompt
                              → LLM_事实与引用审核
                              → End
```

## 四、Start输入

| 名称 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `topic` | String | 是 | 同时作为知识库Query |
| `audience` | String | 是 | 目标受众 |
| `goal` | String | 是 | 内容目标 |
| `source_material` | Long Text | 否 | 用户额外提供的事实素材；可为空 |
| `target_format` | String | 否 | 默认“小红书知识图文” |
| `tone_hint` | String | 否 | 本次表达要求 |
| `image_style` | String | 否 | 图片风格 |
| `page_count` | Integer | 否 | 默认3 |

## 五、新增节点

`IF_必要输入检查`只检查topic、audience和goal。source_material允许为空，因为本版本的新增价值就是从知识库补充主题相关内容。

### 1. `Knowledge_按主题检索课程知识`

- 知识库：`AI产品经理课程知识库_课堂版`；
- Query：直接绑定 `Start.topic`；
- 输出：`retrieved_knowledge`；
- 召回数量：课堂初始建议3—5条；
- 调试阶段不增加复杂过滤条件；
- 必须能够查看命中的文档名和具体片段。

这里不增加“LLM生成检索问题”节点。课堂先让topic直接检索，减少变量和排错成本。

### 2. `IF_知识是否命中`

- `retrieved_knowledge`非空：继续；
- 为空：返回`knowledge_not_found`；
- 不允许在无命中时声称“根据知识库”。

### 3. `LLM_整理知识证据`

- Prompt：`01_整理知识证据Prompt.txt`；
- 输入：retrieved_knowledge、source_material；
- 输出：`evidence_cards`、`source_names`、`conflicts`。

### 4. `LLM_知识增强内容策划`

- Prompt：`02_知识增强内容策划Prompt.txt`；
- 输入：topic、audience、goal、source_material、evidence_cards、target_format；
- 输出：`content_plan`。

### 5. `LLM_知识增强标题正文`

- Prompt：`03_知识增强标题正文Prompt.txt`；
- 输入：topic、audience、goal、source_material、evidence_cards、content_plan、target_format、tone_hint；
- 输出：`copy_package`。

### 6. `LLM_事实与引用审核`

- Prompt：`04_事实与引用审核Prompt.txt`；
- 输入：source_material、retrieved_knowledge、evidence_cards、copy_package、image_script；
- 输出：`review_result`。

## 六、事实规则

```text
允许的事实来源
＝本次source_material
＋知识库实际命中的retrieved_knowledge
```

- source_material与知识片段冲突时，标记冲突并要求人工处理；
- 检索片段不是自动正确，仍需展示来源并审核；
- 不使用模型训练记忆补充关键事实；
- 知识库没有命中时停止，不生成“知识增强版”。

## 七、End输出

```text
status：success / knowledge_not_found / input_required
knowledge_hit
source_names
evidence_cards
conflicts
copy_package
image_script
images_optional
review_result
```

## 八、推荐课堂输入

### 正常命中

```text
topic：RAG适合解决什么问题
audience：刚接触AI产品的初级产品经理
goal：帮助读者判断自己的需求是否应该使用RAG
source_material：留空
target_format：小红书知识图文
tone_hint：清楚、克制、强调判断边界
image_style：简洁编辑感、米白背景、蓝绿色点缀
page_count：3
```

### 无命中

```text
topic：2026年某款手机的实时售价
```

## 九、验收

- [ ] topic能命中对应课程知识；
- [ ] 输出能展示真实文档名；
- [ ] 正文关键结论能回到命中片段；
- [ ] 无命中时明确停止；
- [ ] 不学习或声称学习个人语气；
- [ ] 不包含当前公司、当前业务和租车信息；
- [ ] 不具备保存和发布能力。
