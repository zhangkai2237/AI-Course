# AI产品经理课程案例：电商商品对比工具

> 本项目全部数据、公司名称、用户反馈和业务情况均为教学模拟，不代表任何真实平台。

## 课程用途

该案例贯穿以下课程模块：

1. AI辅助PRD
2. AI生成原型
3. AI生成可交互Demo
4. Vibe Coding与测试迭代

## 建议课堂流程

1. 学员先阅读 `00-需求素材/`
2. 使用Codex生成 `01-需求分析/需求上下文.md`
3. 识别事实、假设、利益相关方意见、产品决策和待确认事项
4. 生成需求澄清问题
5. 补充产品决策
6. 再进入PRD、原型与Demo阶段

## 目录说明

- `00-需求素材/`：故意保留不完整、冲突和噪声的原始材料
- `01-需求分析/`：学员输出模板
- `02-PRD/`：后续PRD模板
- `03-评审/`：多角色评审模板
- `04-原型/`：原型说明模板
- `05-Demo/`：后续开发说明
- `教师参考/`：标准答案、提示词和讲师说明

## 使用提醒

第一次课堂演示时，不要向学员展示 `教师参考/` 目录。
