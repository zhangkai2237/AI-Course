## 🗺️ 第一阶段：AI 赋能核心工作流与实战

### 📂 第一模块：传统PM转型：AI时代的产品经理

- **1\.1 传统PM面临的5个致命问题**

    - 需求红利消失、行业内卷严重

    - 核心竞争力下降、岗位可替代性高

    - 无法理解新技术，逐渐被技术边缘化

    - 个人职业发展遇到明显瓶颈

    - 传统产研工具和方法论的提效遇到瓶颈

- **1\.2 产品经理的两条转型路径**

    - “会用AI的PM” vs “AI原生PM”的本质区别

    - 转型过程中的关键观念转变与思维重塑

- **1\.3 AI产品经理的能力分层体系**

    - 从 L1（原型画图工）到 L5（AI\-Native 架构者）的进阶路径

    - 企业对不同层级 AI 产品经理的核心诉求与能力画像

- **1\.4 行业新机遇解读**

    - 为什么说“AI时代的版本之子是产品经理”

    - 全行业智能化改造带来的岗位井喷与薪资红利

### 📂 第二模块：产品经理必须理解的AI核心认知

- **2\.1 提示词（Prompt）的核心价值与底层逻辑**

    - 什么是提示词？提示词在 AI 系统中的角色

    - 提示词工程（Prompt Engineering）的本质、演进与生命周期

- **2\.2 必须掌握的 AI 8 种核心使用模式**

    - 总结、推断、转换、扩展、对话等 8 大应用模式深度拆解

    - 不同模式在实际产品功能设计中的组合应用场景

- **2\.3 AI 幻觉的产生机理与规避、治理方法**

    - 为什么大模型会“一本正经地胡说八道”

    - 产品设计层面的幻觉治理策略：通过约束、校验与引导进行设计控制

- **2\.4 AI 能力边界界定**

    - 大模型现阶段“能做什么”与“绝对不能做什么”

    - 技术可行性与商业落地边界（成本、体验、合规）的权衡

- **2\.5 新时代下人机协作定位分层**

    - PM 与 AI 的三种演进关系：助理 $\rightarrow$ 同事 $\rightarrow$ 新大陆

    - AI 时代下全新的生产力关系重构

## 🌐 第二阶段：AI原生产品与 Agent 架构设计

> 🎯 **第二阶段核心目标**：
从“会用AI的PM”跨越到“AI原生架构者”，深度掌握复杂 Agent 系统、Multi\-Agent 协同及企业级智能体的规划与设计。

### 📂 第六模块：AI原生产品与Agent核心架构

- **6\.1 什么是 AI\-Native（AI原生）产品？**

    - “传统产品 \+ AI功能” vs “纯 AI 原生产品”的底层设计逻辑碰撞

    - 重新定义用户交互：从 GUI（图形用户界面）到 LUI（语言用户界面）与混合界面（HUI）的演进

- **6\.2 Agent（智能体）的底层四要素架构设计**

    - **Profile（角色定义）**：如何构建清晰、边界明确、具备稳定行为模式的 Agent 人设

    - **Memory（记忆系统）**：短期记忆（Context 缓存）与长期记忆（Vector DB/RAG）的架构设计

    - **Planning（规划能力）**：任务拆解（Task Decomposition）与自我反思（Self\-Reflection）机制设计

    - **Action（执行动作）**：工具调用（Tools/Plugins）的权限边界与触发逻辑

### 📂 第七模块：高级架构演进：从单Agent到多Agent系统

- **7\.1 为什么需要多智能体（Multi\-Agent）系统？**

    - 单智能体的能力上限与在长文本、复杂跨职能任务下的“性能坍塌”

    - 多智能体协作的核心价值：专业分工、相互制衡、流程流水线化

- **7\.2 常见的多智能体协作模式与拓扑结构**

    - 星型架构（主 master 控制）、流水线架构（Sequential Pipeline）、网状自由讨论架构深度剖析

    - 经典开源多智能体框架（如 MetaGPT、AutoGen、Hermes Agent）的产品经理视角拆解

- **7\.3 多智能体系统的产品规划与协同策略**

    - 角色冲突治理、死锁防范、Token 消耗控制与费用预算管理

    - **实战设计**：构建一个包含“策划、撰稿、校对、排版”的自动化媒体矩阵 Agent 团队

### 📂 第八模块：打通外部世界：知识库、函数调用与前沿接口

- **8\.1 检索增强生成（RAG）产品化落地**

    - 知识库建设的产品化四个核心步骤：文档切片（Chunking）、向量化（Embedding）、检索（Retrieval）、重排（Rerank）

    - PM 如何评估与优化 RAG 系统的召回率、准确率与数据安全边界

- **8\.2 函数调用（Function Calling）与外部系统链接**

    - 什么是 Function Calling？让 AI 拥有执行真实业务“动作”的双手

    - API 接口标准化描述撰写、入参出参映射设计及异常处理逻辑（超时、报错、权限控制）

- **8\.3 前沿技术协议演进：MCP（Model Context Protocol）**

    - 什么是 MCP？为什么它是打通大模型与本地/外部系统生态的革命性协议

    - **MCP 架构下的产品设计新机遇**：如何用标准服务开发思维规划全新的应用插件

### 📂 第九模块：大模型选型、价值管理与商业策略

- **9\.1 大模型底座选型指南**

    - 开源模型（Llama、Qwen 等）vs 闭源商用模型（OpenAI、Claude、DeepSeek 等）的深度权衡

    - **选型三要素决策模型**：技术性能（Capability）、综合成本（Cost）、合规/安全性（Security）

- **9\.2 AI 产品的商业化与成本控制**

    - AI 产品的常见收费与计费模式（按量付费、Token 消耗包、订阅制、混合模式）产品设计

    - Token 成本精细化核算、并发限流（Rate Limit）策略与收益率分析模型

- **9\.3 大模型微调（Fine\-Tuning）与垂直行业壁垒**

    - 什么时候该用 RAG？什么时候必须做微调（Fine\-Tuning）？

    - 垂直行业小模型微调的产品日常：数据清洗、语料准备、微调流程与行业壁垒构建
