# 参考产品决策

> 这些是为了保证课程后续原型和Demo可落地而设定的建议答案，不是唯一正确答案。

| 决策主题 | 参考决策 | 理由 |
|---|---|---|
| 一期品类 | 手机 | 数据标准化相对较高，用户场景清晰 |
| 类目范围 | 同一三级类目 | 避免跨品类参数无法映射 |
| 对比对象 | SKU | 价格、容量、库存与具体配置相关 |
| 商品数量 | 2至4个 | 兼顾移动端体验和技术性能 |
| 未登录使用 | 支持 | 降低使用门槛 |
| 保存方式 | 一期仅本地临时保存 | 避免服务端排期 |
| 默认视图 | 核心参数＋只看差异 | 降低认知负担 |
| 全部参数 | 支持展开 | 满足数码用户需求 |
| 价格 | 展示活动价与优惠条件，不承诺统一到手价 | 用户资格差异 |
| 参数缺失 | 显示“暂无数据”，不得推测 | 保持可信度 |
| 参数冲突 | 标注来源并提供反馈入口 | 避免隐藏问题 |
| AI推荐 | 一期不做 | 合规、信任和解释性成本高 |
| 成功指标 | 使用率、完成对比率、详情页返回次数、加购率；转化率作为观察指标 | 避免过早承诺因果 |
