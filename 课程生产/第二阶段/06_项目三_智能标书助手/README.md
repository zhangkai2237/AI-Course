## 网页 Demo 演示顺序

1. 在项目总览点击“开始解析”；
2. 在要求解析页点击要求卡片，观察原文定位；
3. 打开响应矩阵，讲五种响应状态与参标初判；
4. 在标书编辑页生成受控草稿；
5. 在风险检查页运行检查，并模拟处理风险项。
