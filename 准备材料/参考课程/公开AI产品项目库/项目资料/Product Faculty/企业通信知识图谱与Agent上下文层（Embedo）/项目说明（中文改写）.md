# Embedo / Ambito 项目说明

> 本文对应英文 `项目说明.html`，采用中文转述。

## 产品判断

企业知识不只存在于文档库，更存在于会议中形成的决定、邮件里的承诺、聊天中的例外和人与项目的关系。Embedo 试图建立一层结构化上下文，使员工和 Agent 使用同一份、可追溯、权限化的组织事实。

## 关键产品选择

- 原始沟通与结构化实体分开保存，实体只保留 source_id 和逐字片段；
- 权限过滤在检索时执行，不能靠提示词要求模型“不要泄露”；
- 确定性 Python 负责路由，不额外浪费一个路由 Agent；
- Haiku 负责低成本分类，Sonnet 负责提取，低置信度再升级 Opus；
- 人工工作台和 MCP 接口共享同一上下文层；
- 对权限、Schema 等高风险要求设置 100% 硬门槛。

## 产品优势

项目没有只设计一个聊天助手，而是同时考虑写入侧、读取侧、数据模型、来源、权限、MCP、被动提醒和多部署模式。评测也按分类、提取、解析、升级、承诺解决判断和权限拆开，而不是用单个总分掩盖失败。

## 主要风险

- 真实企业连接器和授权远比原型复杂；
- 跨用户、团队和租户权限错误属于严重事故；
- 自动聚类项目和责任人归属可能伤害组织信任；
- 员工可能不愿让系统持续分析沟通；
- “安心”和“组织可见性”必须转化为留存、行动率和纠错率等指标。

## 学习重点

本项目适合学习企业 AI 基础设施产品：价值并不完全来自生成答案，而来自稳定接入、持续结构化、来源追踪、权限隔离和为其他 Agent 提供上下文。
