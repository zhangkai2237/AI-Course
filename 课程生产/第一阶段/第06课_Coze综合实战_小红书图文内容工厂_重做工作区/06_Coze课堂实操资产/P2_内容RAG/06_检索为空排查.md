# P2内容检索为空排查

按顺序检查，不要先反复改Prompt。

## 1. 原句测试

从K001或K002的已解析切片中复制一段独特原句，直接放入知识检索节点Query。

- 能命中：知识库和索引正常；
- 不能命中：检查文档处理状态、知识库绑定、版本同步和检索配置。

## 2. 标准问题测试

依次测试：

```text
RAG适合解决什么问题
RAG为什么不能完全消除幻觉
RAG离线建库和在线问答有什么区别
```

## 3. 节点绑定

正式画布中：

```text
Knowledge.Query = Start.topic
```

不需要LLM生成检索问题，不需要style_query，也不需要固定的语气标识。

## 4. 调试设置

- 召回数量先设3—5；
- 临时降低最低匹配门槛；
- 暂时关闭复杂过滤和重排；
- 查看真实命中文档名和片段，而不只看最终正文。

字段名称以当前Coze界面为准。
