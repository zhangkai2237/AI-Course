# 模块04｜三工具与动态路径

> 建议时长：15分钟  
> 核心问题：怎样用一个案例真正表现Agent的动态选择？

## 一、教学目的

用三个明确工具和三类返回状态，展示同一个用户目标为什么会产生不同执行路径。

## 二、工具一：查询经营数据

```text
query_store_metrics
```

### 输入

- `store_id`
- `start_date`
- `end_date`
- `metrics`

### 成功输出

- 指标值；
- 环比变化；
- 数据完整性；
- 诊断标签；
- 诊断依据。

### 异常

- 门店不存在；
- 用户无权限；
- 日期范围无数据；
- 查询超时；
- 指标不支持。

### 风险

读取类；权限校验后可以自动调用。

## 三、工具二：查询活动规则

```text
search_activity_rules
```

### 输入

- `store_id`
- `rule_type`
- `query_date`

### 成功输出

- 规则名称；
- 适用范围；
- 门槛与限制；
- 当前版本；
- 生效和失效时间；
- 来源。

### 异常

- 未找到适用规则；
- 多条规则冲突；
- 规则失效；
- 知识库版本过旧。

### 风险

读取知识类；可以自动调用。

## 四、工具三：创建活动草稿

```text
create_campaign_draft
```

### 输入

- `store_id`
- `activity_type`
- `target_segment`
- `offer`
- `threshold`
- `start_date`
- `end_date`
- `budget_limit`
- `user_confirmed`

### 成功输出

- 草稿ID；
- 草稿内容；
- 创建时间；
- 当前状态；
- 后续审批要求。

### 异常

- 无创建权限；
- 时间冲突；
- 优惠力度越界；
- 预算不足；
- 系统写入失败。

### 风险

写入类；执行前必须展示参数并获得明确确认。只有应用已经记录用户确认时，`user_confirmed` 才能为 `true`。

## 五、路径一：新客下降

模拟工具返回：

```text
new_customer_count: 120
period_change: -25%
data_completeness: complete
diagnosis_label: new_customer_decline
diagnosis_reason: 环比下降超过教学阈值20%
```

Agent路径：

```text
查经营数据
→ 读取新客下降标签
→ 查当前新客活动规则
→ 生成活动方案
→ 展示完整参数
→ 等待用户确认
→ 创建草稿
```

## 六、路径二：补贴异常

模拟工具返回：

```text
new_customer_change: +2%
subsidy_change: +80%
diagnosis_label: subsidy_efficiency_risk
```

Agent路径：

```text
查经营数据
→ 新客正常、补贴异常
→ 不调用新客活动规则
→ 查询补贴与成本限制
→ 输出优化建议
→ 不创建新活动
```

教学重点：同一个目标，Agent根据结果改变工具选择。

## 七、路径三：数据不足

模拟工具返回：

```text
status: insufficient_data
available_days: 3
suggested_action: ask_to_expand_date_range
```

Agent路径：

```text
查经营数据
→ 发现只有3天数据
→ 询问是否扩大到最近30天
→ 用户同意后重新查询
→ 用户拒绝则停止
```

本路径不再增加“同区域参考门店”工具，保持三工具方案一致。

## 八、路径对比

| 工具结果 | 下一步 | 是否创建草稿 |
|---|---|---|
| 新客下降 | 查新客规则、生成方案 | 确认后可以 |
| 补贴异常 | 查补贴限制、给优化建议 | 不创建 |
| 数据不足 | 追问是否扩大日期 | 暂不创建 |
| 规则冲突 | 暴露冲突、转人工 | 不创建 |
| 无权限 | 拒绝并提示合法路径 | 不创建 |

## 九、教师动作

- 隐藏后续路径，先逐次揭晓工具返回；
- 每次返回后让学员投票“下一步调用什么”；
- 追问“为什么不能固定按三个工具顺序全部调用”；
- 强调诊断阈值来自确定性规则，不由Agent自由创造。

## 十一、来源与边界

- 主来源：A1 05:03-09:35；A2 10:39-12:32；A5 P306-P362。
- 课程加工：三个模拟工具、诊断标签和三条路径。
- 不接真实数据库，不声称案例为真实项目。

## 十二、本模块验收

学员能够说明：

> Agent不是按固定顺序把所有工具调用一遍，而是根据工具返回状态选择下一步或停止。
