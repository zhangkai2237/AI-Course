# 模块07：总结、保存与课后任务——老师版讲义

> 时间：175—180分钟  
> 目标：保存四个版本和测试证据，完成认知收口  
> 产物：P0—P3、测试记录和个人迁移作业方向

## 一、老师收口讲法

“今天我们没有做四个互不相干的Demo，而是把同一个项目升级了四次。

Prompt决定一个节点怎样理解输入、遵守要求并组织输出；Workflow把可提前确定的步骤做成可重复、可观察的流程；RAG为流程提供指定、可更新的知识；Agent根据目标和当前状态决定追问、搜索、调用流程、保存还是停止。

能力不是越多越好。每增加一层，都同时增加配置、调试、评测和风险治理成本。AI产品经理真正需要会的，是知道问题出在哪一层，以及是否值得增加这一层。”

## 二、学员保存动作

统一命名：

```text
姓名_P0_小红书文案生成器
姓名_P1_小红书图文Workflow
姓名_P2_个人语气_RAG图文Workflow
姓名_P3_小红书内容策划Agent
```

要求保存：

- 项目链接或画布截图；
- 一次正常运行结果；
- 一次边界测试结果；
- 一次修改前后记录；
- 四版本能力对照表。

如果平台链接只能在课堂工作区内部打开，应同时保留关键截图，避免课后失去权限。

## 三、隐私与权限检查

让学员最后勾选：

- [ ] 没有当前公司和内部业务信息；
- [ ] 没有真实客户、商家或经营数据；
- [ ] 没有账号、Token、密钥和接口地址；
- [ ] 历史语气样本由本人撰写并已删除敏感事实；
- [ ] AI生成内容已标记需要人工检查；
- [ ] 没有自动发布到任何外部平台；
- [ ] 模拟保存没有被描述为真实发布。

## 四、课后作业

从四个迁移挑战中选择一个完成V1.0：

1. 差评回复Prompt；
2. 60秒口播Workflow；
3. 个人语气RAG；
4. 新品上市内容策划Agent。

作业必须包含：

- 使用者和具体任务；
- 输入与输出；
- Coze配置截图；
- 三条测试，其中至少一条是边界或失败测试；
- 一次修改前后对比；
- 为什么选这种能力，而不是另外三种；
- 使用了哪些虚构或公开材料；
- 当前版本仍不能做什么。

## 五、老师点评标准

不要主要按文案是否“好看”打分，建议按以下维度：

| 维度 | 判断问题 |
|---|---|
| 任务清楚 | 使用者、输入、输出是否明确 |
| 能力匹配 | 是否为了解决真实问题而选Prompt/Workflow/RAG/Agent |
| 运行证据 | 是否有真实节点或工具调用记录 |
| 边界意识 | 是否测试缺信息、无知识、失败或越权 |
| 迭代过程 | 是否有修改前后对比 |
| 隐私安全 | 是否只使用公开或虚构材料 |

## 六、和后续课程的关系

本课到Coze搭建和验证为止。后续课程再处理：

- 如何把能力写成PRD；
- 如何设计用户交互和Demo；
- 如何建立系统测试集；
- 如何补权限、安全和治理；
- 如何估算调用成本和业务价值；
- 是否以及怎样进入真正产品化。

## 七、最后一句
