1. 每个正式课次内部固定分为“讲义与材料”和“PPT”；
2. 同一课存在多套视觉版本时，明确标记“正式版”与“备选版”；
3. 尚未确定进入课程的方向放入 `90_待定项目/`；
4. 被新版本替代的内容移入 `99_历史归档/`，不直接删除；
5. 渲染图、检查报告和构建脚本放在对应 PPT 目录内部，不散落到第二阶段根目录。
