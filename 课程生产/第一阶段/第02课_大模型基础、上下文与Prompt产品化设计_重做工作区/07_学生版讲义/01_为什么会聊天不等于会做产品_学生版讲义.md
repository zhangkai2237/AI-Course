# 模块01：为什么“会聊天”不等于“会做产品”

> 课堂时间：0—7分钟  
> 本模块任务：发现问题，理解本课为什么不只是Prompt技巧课

## 一、两个现象

### 现象1：同一句话可能得到不同回答

在同一个AI产品中输入同一句话，两次结果可能出现不同观点重点、表达方式和例子，也可能一次满足要求、一次遗漏要求。

结果也可能相同。“可能不同”不等于“每次必然不同”。

### 现象2：模糊指令有时也能得到不错答案

例如：

> 帮我整理一下这次销售拜访。

模型可能生成一段语言通顺的总结，但产品经理还不能判断它是否可用，因为没有说清：

- 整理给谁看；
- 在什么工作时点使用；
- 需要摘要、异议、商机还是行动项；
- 哪些内容不能推测；
- 缺失信息怎样处理；
- 结果要进入哪里；
- 怎样才算合格。

## 二、个人使用和产品交付的区别

### 个人使用

- 结果不好时可以继续追问；
- 临时补充背景；
- 自己判断哪些内容不可信；
- 手工复制和修改；
- 偶尔成功也可能觉得有帮助。

### 产品交付

- 不同用户的输入方式不同；
- 用户未必理解Prompt；
- 同类任务会重复发生；
- 结果要进入真实工作流程；
- 错误可能影响客户和业务动作；
- 产品需要知道怎样检查和改进。

因此：

> 会使用聊天工具，不等于已经完成AI产品设计。

## 三、影响AI结果的因素

| 因素 | 含义 |
|---|---|
| 模型能力 | 模型是否具备完成任务所需能力 |
| 生成机制 | 同一输入可能存在多种合理后续 |
| 任务定义 | 是否明确服务对象、目标和边界 |
| 上下文 | 模型本次获得了哪些材料和规则 |
| 输出标准 | 是否规定字段、证据和缺失处理 |
| 产品流程 | 结果是否经过编辑、确认和后续动作 |

不要把所有问题都简单归因于“幻觉”或“Prompt写得不好”。

## 四、本课不是什么

本课不是：

- 背诵万能Prompt；
- 学习所谓神奇咒语；
- 比较谁的Prompt更长；
- 学习某个工具的按钮；
- 认为调低Temperature就能解决全部问题。

本课训练的是：

> 从产品目标出发，定义输出和上下文，组织结构化Prompt，再把Prompt封装成用户可以低门槛使用的产品。

## 五、先记住

1. 模糊输入偶尔成功，不代表可以稳定交付；
2. AI结果受模型、任务、上下文、规则和流程共同影响；
3. Prompt产品化不是教用户写长Prompt；
4. 产品需要让专业要求能够被重复执行。
