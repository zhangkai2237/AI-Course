# 模块06：四版本统一测试——老师版讲义

> 时间：163—175分钟  
> 目标：在本次事实不变的情况下，比较流程、语气和动态工具能力

## 一、老师先理解

P2不提供任何历史事实，只提供从样本中抽象出的个人表达语气。因此本模块的核心对照应检查：

- 事实是否始终只来自本次输入；
- P2是否在表达方式上形成稳定差异；
- RAG是否把历史事实错误带入新文章；
- P3是否只在合适条件下调用P2和其他工具。

## 二、建议讲法

“现在四个版本使用同一份事实。P2并不应该比P1知道更多事实，它只应该更像老师平时的表达。只要P2多出一条历史公司、项目或数据，就说明语气和事实没有隔离好。”

## 三、T1：完整事实生成

四版使用统一正常输入。

观察：四版能否完成；P0或P1是否已经足够；复杂版本带来什么额外成本。

## 四、T2：个人语气对照

重点比较P1与P2：

- 开头是否更符合老师习惯；
- 句子节奏是否相近；
- 论述是否保持“问题—误区—方法”；
- 结尾是否给行动建议而非强销售；
- 两版事实是否完全一致。

让学员先盲看，再展示P2抽象语气卡。

## 五、T3：历史事实隔离

选择一篇含旧公司、旧项目或数据的测试样本，但这些内容不在本次source_material中。

正确结果：

- 语气卡不含历史事实；
- 新文章不含历史事实；
- 审核没有发现事实迁移；
- 如出现迁移，P2判定失败，不因“很像老师”而通过。

## 六、T4：缺少必要输入

输入：

> 帮我做一篇AI产品内容。

观察：

- P0主要依赖Prompt规则；
- P1/P2由输入检查停止；
- P3主动追问，并在信息完整后再决定是否调用P2。

## 七、T5：近期外部材料

P0—P2默认没有外部搜索能力。P3只有配置搜索工具并实际成功调用后，才能声称使用近期资料。

个人语气样本库不是实时信息来源。

## 八、T6：直接发布

所有版本均没有真实发布能力。生成、保存、审核和发布必须区分。

## 九、课堂对照表参考

| 对比项 | P0 | P1 | P2语气RAG | P3 |
|---|---|---|---|---|
| 完整输入生成 | 可以 | 可以 | 可以 | 可以 |
| 固定流程 | 弱 | 强 | 强 | 可调用 |
| 个人表达语气 | 依赖手写Prompt | 依赖手写Prompt | 检索样本并抽象 | 通过P2使用 |
| 历史事实隔离 | 无历史样本 | 无历史样本 | 必须隔离 | 依赖P2隔离 |
| 跨体裁语气迁移 | 弱 | 弱 | 可测试 | 通过P2使用 |
| 缺信息处理 | 依赖Prompt | 固定分支 | 固定分支 | 主动追问 |
| 按需搜索 | 无 | 无 | 无 | 配置后可选 |
| 配置测试成本 | 低 | 中 | 中高 | 高 |

## 十、组合关系

```text
Agent
  └─ 调用个人语气RAG Workflow
       ├─ Workflow控制固定步骤
       ├─ RAG检索历史表达样本
       ├─ 语气节点只输出抽象风格卡
       └─ LLM节点仍由Prompt定义行为

事实：本次source_material
语气：style_profile
体裁：target_format＋Prompt
```

## 十一、通过标准

- 至少完成T1—T4；
- P2不增加历史事实；
- 能指出P1和P2的一处可解释语气差异；
- 不把Agent评价为所有任务的默认最优；
- 能说清语气、事实和体裁分别从哪里来。

## 十二、转场

“最后把四个版本、测试记录和语气卡保存好。今天留下的不是一篇像老师的小红书，而是一套知道数据从哪里来、怎样隔离和怎样验证的流程。”
