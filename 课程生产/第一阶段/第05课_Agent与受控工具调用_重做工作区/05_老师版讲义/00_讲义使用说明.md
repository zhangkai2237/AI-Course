# 第05课老师版讲义使用说明

> 课程名称：《Agent与受控工具调用》  
> 基准时长：138分钟，含5分钟休息  
> 适用对象：第一次系统学习Agent的初级产品经理  
> 使用前提：老师不需要会开发Agent，但必须提前跑通课堂Demo

## 一、讲义标记

- **【老师先理解】**：备课时必须弄懂，不必全部照讲；
- **【建议讲法】**：可以直接转化成课堂语言；
- **【互动】**：提问、学员动作和预期回答；
- **【屏幕/板书】**：课堂必须出现的结构；
- **【纠偏】**：常见错误及处理；
- **【转场】**：与下一模块衔接；
- **【不要展开】**：本课边界。

## 二、授课底线

1. 不把Agent说成“更强的聊天机器人”；
2. 不把Workflow说成落后的方案；
3. 不说模型直接执行了数据库或业务系统操作；
4. 不让模型自行定义经营异常阈值；
5. 不把一次成功Demo说成产品已经可上线；
6. 不用真实公司数据、账号、接口或密钥；
7. MCP和Multi-Agent只讲定位，不做安装搭建。

## 三、课前必须准备

- 已配置好的“门店经营助手”；
- 三个模拟工具及固定返回；
- T1—T5五条测试的完整运行记录；
- 工具调用名称、参数和返回结果截图；
- 创建草稿前的确认卡；
- 平台不可用时的静态截图或返回卡；
- 可打印的《Agent受控执行设计与测试表》。

## 四、建议备课顺序

1. 先读 `01_知识点来源溯源表.md`，知道每个概念来自哪里；
2. 再读 `03_逐模块详细内容设计`，理解课程完整逻辑；
3. 使用本讲义完成一次138分钟试讲；
4. 按T1—T5重新跑一遍Demo；
5. 最后检查讲义、PPT、练习纸中的工具参数是否一致。
