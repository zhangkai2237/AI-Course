# 三个模拟工具统一说明

> 本文件是讲义、PPT、练习纸和Coze配置的统一口径。修改任何字段前，必须同步检查所有正式材料。

## 1. query_store_metrics

用途：查询指定门店和日期范围内的经营指标，并返回由确定性规则产生的诊断标签。

输入：

- `store_id`
- `start_date`
- `end_date`
- `metrics`

成功返回：

- `status`
- `metric_values`
- `period_change`
- `data_completeness`
- `diagnosis_label`
- `diagnosis_reason`

异常：`STORE_NOT_FOUND`、`NO_PERMISSION`、`NO_DATA`、`TIMEOUT`、`UNSUPPORTED_METRIC`。

权限：读取类；校验用户门店权限后可执行。

## 2. search_activity_rules

用途：查询指定门店在指定日期适用的活动或成本规则。

输入：

- `store_id`
- `rule_type`
- `query_date`

成功返回：

- `status`
- `rule_name`
- `scope`
- `requirements`
- `limits`
- `effective_date`
- `expiry_date`
- `source`

异常：`RULE_NOT_FOUND`、`RULE_CONFLICT`、`RULE_EXPIRED`、`KNOWLEDGE_OUTDATED`。

权限：读取知识类；可自动执行并记录来源。

## 3. create_campaign_draft

用途：使用用户已经确认的参数创建活动草稿。

输入：

- `store_id`
- `activity_type`
- `target_segment`
- `offer`
- `threshold`
- `start_date`
- `end_date`
- `budget_limit`
- `user_confirmed`

成功返回：

- `status`
- `draft_id`
- `draft_content`
- `created_at`
- `approval_requirement`

异常：`NO_PERMISSION`、`TIME_CONFLICT`、`OFFER_OUT_OF_RANGE`、`BUDGET_EXCEEDED`、`WRITE_FAILED`。

权限：写入类。执行前必须展示完整参数并获得明确确认；未确认时 `user_confirmed` 不得为 `true`。

边界：只能创建草稿，没有发布能力。
