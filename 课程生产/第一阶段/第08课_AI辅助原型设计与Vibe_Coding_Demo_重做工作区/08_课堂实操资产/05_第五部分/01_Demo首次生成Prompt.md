# Demo 首次生成 Prompt

```text

请先列出读取依据、实现清单和验收清单。发现冲突或缺失时停止并列出问题。得到确认后再生成demo/index.html、启动预览、逐项测试，并输出已实现能力、模拟边界和未实现能力。
```
