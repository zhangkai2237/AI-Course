# 第一部分错误 Demo 准备说明

> 这是一件教学道具，用来制造“第一眼完整、对照决策后问题明显”的认知反差。

## 最低要求

错误 Demo 保持视觉完整、可以点击，并至少包含以下六个问题：

1. 出现“AI推荐最佳商品”；
2. 支持选择第5个商品；
3. 没有区分具体SKU；
4. 展示确定的统一到手价；
5. 参数缺失时自动补齐；
6. 显示“云端保存成功”。

可选增加：

- 跨品类对比；
- 强制登录；
- 参数冲突不展示来源；
- 商品下架后仍可正常购买。

## 演示路径

```text
选择两个商品
→ 加入第5个商品
→ 进入对比页
→ 查看AI推荐
→ 查看价格与缺失参数
→ 点击保存
```

## 课堂原则

- 不提前标注错误；
- 不依赖现场随机生成，课前准备稳定版本；
- 错误必须能在《第七课产品决策摘要》中找到依据；
- 不用纯视觉审美问题代替产品问题；
- 第一部分只找错，不现场修复。
