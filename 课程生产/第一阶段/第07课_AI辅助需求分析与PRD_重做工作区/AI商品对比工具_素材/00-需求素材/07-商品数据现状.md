# 商品数据现状

## 商品层级

- SPU：标准产品，例如“星云 X1 手机”。
- SKU：具体可购买配置，例如“星云 X1 12GB+256GB 黑色”。
- 同一SPU下，不同SKU可能存在容量、颜色、价格、库存和套餐差异。
- 某些商家会重复创建近似SPU，平台尚未完全去重。

## 参数数据来源

1. 平台标准属性库
2. 品牌方提供的结构化数据
3. 商家自行填写
4. 历史商品迁移数据

## 手机品类数据质量（教学模拟）

| 指标 | 当前值 |
|---|---:|
| 核心参数完整率 | 82% |

| 商家填写与平台标准值冲突比例 | 6% |
| SKU与SPU关联异常比例 | 2.3% |

## 常见问题

- “电池容量”可能写成“5000mAh”“5,000 毫安时”或“5000”。
- “机身重量”可能使用克或千克。
- “快充功率”有时只写“支持快充”，没有具体功率。
- 屏幕尺寸可能包含主屏、外屏和折叠屏展开尺寸。
- 芯片名称存在简称和营销名称。
- 颜色字段通常不影响核心性能，但影响SKU识别。
- 售后服务由平台、店铺和品牌共同决定，难以只用一个字段表达。

## 品类差异

| 品类 | 核心参数标准化程度 | 主要难点 |
|---|---:|---|
| 手机 | 较高 | SKU、优惠、参数命名 |
| 笔记本电脑 | 中等 | 配置组合复杂、型号近似 |
| 平板 | 中等 | 套餐和配件差异 |
| 智能穿戴 | 中等 | 兼容性和生态差异 |
| 家电 | 较低 | 安装、服务和规格差异大 |
