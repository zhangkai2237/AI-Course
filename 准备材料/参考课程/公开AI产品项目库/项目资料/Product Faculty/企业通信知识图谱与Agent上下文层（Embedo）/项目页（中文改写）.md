# Embedo / Ambito：企业通信知识图谱与 Agent 上下文层

> 本文为公开项目页的中文改写；英文网页保留在 `项目页.html`。

## 项目概览

Embedo（公开材料中也称 Ambito.ai）把会议、邮件、日历和企业聊天中的决策、承诺、行动项、开放问题和项目关系，转化成带来源和权限的企业知识图谱。该上下文层既供员工通过仪表盘和 Ask Ambito 使用，也供企业内部 AI Agent 通过 MCP 查询。

## 产品背景

企业真正重要的知识经常停留在沟通中，没有进入正式文档。知识工作者很难持续跟踪谁承诺了什么、哪些项目停滞、哪些决定已经发生；内部 Agent 也只能访问静态文档，缺少组织的真实运行上下文。

## 两类用户

- 人类用户：跨团队协调频繁、对结果负责的知识工作者；
- 机器用户：需要企业上下文的内部 AI Agent；
- 购买者：建设企业 AI、知识基础设施和协同可见性的组织。

## 核心能力

1. 接入会议、邮件、日历和 Slack/Teams；
2. 提取决策、承诺、行动项和项目；
3. 保存置信度和逐字来源片段；
4. 自动聚类项目并识别停滞或无人负责事项；
5. 通过仪表盘和问答提供带引用的综合结果；
6. 通过 MCP 向 Agent 提供权限过滤后的上下文；
7. 支持 SaaS、BYOK 和 VPC 等企业部署模式。

## 核心差异化

产品不与基础模型竞争“更聪明”，而是积累企业独有、长期、可追溯、带权限的上下文层。模型可以替换，但组织知识图谱和使用反馈可以持续形成壁垒。

## 成熟度

公开方案在架构、模型分层、权限和评测上较强。真正难点是企业连接器、OAuth 授权、跨用户和租户隔离、用户信任与真实部署，而不是实体提取本身。
