# 第02课PPT逐页内容二次Review

> Review范围：第1—49页逐页内容稿及直接关联的作业要求  
> Review方式：不沿用第一次Review结论，重新检查概念准确性、答案揭示、上屏密度和学习目标闭环  
> 最终结论：发现4类实质问题并已修正；内容层面可以进入正式PPTX制作

---

## 一、本轮发现并修正的问题

### 1. 第38页和第40页提前提示案例答案

原第38页直接摘录：

- 确认按5家准备；
- 可能增加到8家；
- 不是正式工期承诺；
- 不能承诺上线时间。

这些正是第39—41页要求学员发现的核心错误。第40页的“合格表达”又直接提示了“把可能写成确定”这一答案，导致练习看似让学员找错，实际上PPT已经圈出了答案。

已修正：

- 第38页只保留证据扫描方法，不再摘录关键原文；
- 使用F事实、U不确定、A行动、R风险四类扫描标记；
- 第40页换成不对应本案例核心答案的通用“遗漏截止时间”示例；
- 具体答案仍只在第41页、学员完成练习后揭示。

### 2. Token示例把中文短语画成单个Token

原第8—10页用“跑步、散步、见朋友”等短语作为“候选Token”。不同Tokenizer可能把这些短语切成一个或多个Token，直接标为单个Token不严谨，也与第14页“Token不固定等于词”冲突。

已修正：

- 页面改称“候选后续”，明确可能包含多个Token；
- 概率图标注“候选短语和数字均为教学示意”；
- 老师备注增加：图中短语是对多条生成路径的可读化简化，不是模型真实Token切分。

### 3. 上下文窗口和实际上下文定义混在一起

原第16页把上下文窗口写成“本次实际提供给模型的信息空间”，容易把容量边界与实际放入的内容混为一谈。

已修正：

- 上下文窗口：一次调用可容纳输入与输出Token的有限空间；
- 实际上下文：本次真正放进去的指令、输入、历史和材料；
- 明确具体上限依模型和接口而异。

### 4. 作业没有强制迁移风险处理能力

课堂V0.3同时训练“信息供给”和“风险处理”，但原必做作业只要求信息供给，风险处理全部被放入进阶版，导致核心学习目标没有进入最低验收标准。

已修正：

- 必做版至少选择1项高风险结果；
- 说明它应该普通展示、建议检查还是必须确认；
- 进阶版再补齐主要风险字段的证据、权限和确认动作；
- 已同步PPT第48页、老师讲义、学生讲义、详细内容设计和课后作业模板。

## 二、上屏密度复查

### 已优化

第48页原来有12条作业要求，1分20秒内无法阅读。现压缩为5组必做任务和4组进阶任务，详细字段由作业模板承载。

### 制作PPTX时仍需重点处理

| 页码 | 风险 | 制作要求 |
|---:|---|---|
| 15 | 7类上下文组成容易拥挤 | 使用容器图逐项进入，不做整页文字列表 |
| 23 | 练习要求和候选信息较多 | 左任务、右信息卡；逐步揭示，不能全部同时高亮 |
| 24 | 六要素一页6卡 | 每卡只保留名称和一个检查问题 |
| 39 | 基线结果文本较长 | 高亮关键句，但不能提前标注错误类型 |
| 41 | 完整答案有8条 | 左右各4条，按点击揭示；课堂重点讲4—5条 |
| 43 | 真实输出长度未知 | 只展示与本轮验收有关的原文节选并标“节选” |
| 48 | 作业信息仍较多 | 必做区占65%，老师只讲合格边界，不逐条朗读 |

## 三、课程逻辑复查

### 主线完整

```text
生成机制
→ 上下文容量与选择
→ 从输出反推输入和规则
→ 结构化Prompt
→ 信息供给与风险处理
→ 案例找错、修改和复测
→ 判断是否超出单次Prompt
→ 课后迁移
```

### 与第0课不重复

- 第0课解决“这个场景是否值得做、AI参与什么环节”；
- 第2课假设场景已经决定做，训练“怎样让模型与产品稳定完成任务”。

### 对零基础学员可执行

- 不要求背CRISPE；
- 不要求解释Transformer、Attention或采样算法；
- 不要求在6分钟内掌握RAG、Workflow、Agent或MCP定义；
- 基准版只完成Prompt关键骨架，不从空白写完整长Prompt；
- 作业必做版只增加1项最低风险处理，不要求完整权限系统。

## 四、时间复查

49页、120分钟基准版仍然合理，但它依赖以下执行方式：

- 概念页不逐字念屏幕；
- 第41页不讲完全部8条；
- 第48页不逐项解释完整模板；
- 课堂练习计时真实执行；
- 互动充分时允许延长到125—130分钟。

不建议为了严格卡120分钟删除V0.1、V0.2、V0.3、案例复测或风险处理。若需要压缩，优先减少老师补充例子和现场分享人数。
