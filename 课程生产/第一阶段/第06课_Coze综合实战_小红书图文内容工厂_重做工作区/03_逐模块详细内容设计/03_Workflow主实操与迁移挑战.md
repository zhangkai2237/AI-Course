# 模块03：Workflow主实操与迁移挑战

> 时间：38—83分钟  
> 主实操：37分钟  
> 迁移挑战：8分钟  
> 产出：P1小红书图文Workflow＋60秒口播挑战版

## 一、本轮解决的问题

P0把角度、标题、正文、图片脚本和检查全部塞在一个Prompt里，容易出现：

- 某一部分缺失；
- 无法单独重跑；
- 不知道哪一步出错；
- 输入缺失时仍继续生成；
- 图片与正文主题不一致。

本轮将内容生产拆成稳定SOP。

## 二、目标流程

```text
Start
→ 必要输入检查
→ 内容角度与大纲
→ 标题与正文
→ 图片脚本
→ 图片生成 / 图片Prompt
→ 内容审核
→ End
```

## 三、节点设计

### 节点1：Start

输入沿用P0，并增加：

- `image_style`
- `page_count`，默认3张内页。

### 节点2：必要输入检查

使用条件节点或等价能力检查：

- `topic`是否为空；
- `audience`是否为空；
- `source_material`是否为空。

缺失时进入“补充信息”结束分支；完整时进入内容角度节点。

### 节点3：内容角度与大纲

输入：主题、受众、目标、素材。

输出：

- 受众痛点；
- 核心观点；
- 内容切入角度；
- 四段式大纲；
- 读者行动。

节点Prompt只做内容策划，不直接写完整正文。

### 节点4：标题与正文

输入：原始变量＋节点3输出。

输出：

- 5个标题；
- 正文；
- 标签；
- 封面短句。

要求只使用 `source_material` 和大纲中已有事实。

### 节点5：图片脚本

输入：标题、正文、图片风格、页数。

输出：

- 封面画面；
- 3张内页标题；
- 每页要点；
- 版式建议；
- 每张图对应的图片提示词。

### 节点6：图片生成或备用输出

优先路线：调用授课工作区已经实测可用的图片生成能力。

最低路线：如果图片节点、模型额度或账号权限不稳定，直接输出图片提示词，并使用老师预生成图片完成后续审核。

本课验收重点是Workflow能够产生图片输入，不把图片模型可用性作为学员是否通过的唯一条件。

### 节点7：内容审核

输入：正文、图片脚本和原始事实。

输出：

- 事实是否来自输入；
- 是否存在夸张承诺；
- 标题正文是否一致；
- 图片文案是否过长；
- 需要人工修改的内容；
- `review_status`：pass / revise。

### 节点8：End

统一返回：

- 标题；
- 正文；
- 标签；
- 封面文案；
- 内页脚本；
- 图片或图片提示词；
- 审核状态与建议。

## 四、主实操步骤

### 第一步：复制P1半成品

老师已搭好Start、End和基础连线。学员负责：

- 配置条件；
- 完成三个LLM节点Prompt；
- 绑定变量；
- 检查输出；
- 运行测试。

### 第二步：先单节点调试

不要第一次就运行完整Workflow。

调试顺序：

1. 内容角度；
2. 标题正文；
3. 图片脚本；
4. 审核；
5. 完整运行。

每次检查真实输入和输出，发现空变量立即停止排查。

### 第三步：正常测试

使用统一输入运行，记录：

- 运行过哪些节点；
- 每个节点耗时；
- 标题正文是否完整；
- 图片脚本是否一致；
- 审核是否正确发现风险。

### 第四步：缺信息测试

删除 `source_material`。

预期：Workflow进入缺信息分支，不运行后续生成节点。

### 第五步：制造一个节点Bad Case

将图片页数改成5，但图片脚本节点仍固定只输出3页。

让学员观察：

- 变量与Prompt约束冲突；
- 应修改哪个节点；
- 为什么不是回到总Prompt盲目加要求。

## 五、最低完成线

- 必要输入检查有效；
- 正常路径能到End；
- 缺信息路径不会继续生成；
- 至少查看三个节点的真实输入输出；
- 能指出一个错误属于哪个节点。

## 六、迁移挑战：60秒短视频口播稿

复制P1，只修改下游节点，不重新搭流程。

保留：

- 输入检查；
- 内容角度；
- 内容审核。

替换：

- 标题正文节点 → 60秒口播脚本；
- 图片脚本节点 → 镜头脚本；
- 图片生成 → 画面提示或B-roll建议。

新输出：

- 3秒开头钩子；
- 45秒主体；
- 12秒总结与行动；
- 分镜；
- 字幕重点；
- 风险提示。

## 八、常见错误

- 一个LLM节点仍承担全部任务，只是外面多画了节点；
- 上游输出没有作为下游输入；
- 变量名改变后没有同步；
- 只看最终答案，不看具体节点；
- 图片生成失败导致全班停住；
- 迁移挑战从空白开始，浪费时间。
